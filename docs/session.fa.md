# مالکیت نشست کلاینت، عملیات و شمارش معکوس

[English](session.md) · [فارسی](session.fa.md)

[SessionProvider](../src/features/auth/SessionProvider.tsx) زبان از قبل داده‌شده
به next-intl را مصرف و /account/me را با کلاینت HTTP بررسی‌شده می‌خواند. مالک کوکی،
نوسازی توکن، مجوز یا انتخاب زبان نیست؛ API مستقل مرجع می‌ماند.

هر snapshot متعلق به یک کلید زبان/نوسازی است. تغییر کلید، حساب قدیم را تا پایان
خواندن جدید پنهان می‌کند. پاکسازی effect خواندن آغازکننده را لغو می‌کند؛ موفقیت یا
خطای دیررس، حتی با انتقال مصنوعی نادیده‌گیرندهٔ signal، دادهٔ قدیمی نصب نمی‌کند.
۴۰۱ خواندن حساب، نشست ناشناس بدون خطای نمایشی است. شکست دیگر نمایش داده می‌شود و
refresh امکان تلاش مجدد صریح می‌دهد.

generation فقط‌خواندنی همان نسخهٔ درخواست موجود را برای مالکیت فرم در اختیار
می‌گذارد. در آغاز refresh یا تغییر زبان، حتی برگشت به زبان قبلی، افزایش می‌یابد.
پذیرش تغییر حساب آن را افزایش نمی‌دهد. این مقدار مالکیت محلی درخواست است و توکن
نشست API یا مقدار مجوز نیست.

شنوندهٔ kernel:session-expired خواندن تازه را آغاز و هنگام unmount حذف می‌شود.
دادهٔ پذیرفته‌شدهٔ تغییر فقط snapshot بارگذاری‌شدهٔ خودش را عوض می‌کند؛ callback
قدیمی نشست جدید را بازنویسی نمی‌کند. مصرف بیرون provider خطای صریح دارد. جداسازی
کوکی و مسیر کامل ورود/خروج مرورگر به برنامهٔ قابل اجرا و fixture مربوط به API نیاز
دارند.

## مالکیت عملیات فرم

[فرم احراز هویت و حساب](forms.fa.md) مالک محلی را با زبان، نسل نشست و هویت حساب
کلیدگذاری می‌کند. تغییر مالک، فرم را remount و مقدار محلی تغییرکرده و بازخورد یا
ناوبری در حال انتظار را پیش از پایان خواندن حساب جدید بی‌اعتبار می‌کند. پاسخ ۴۰۱
عملیات عمومی ورود/ثبت‌نام/OTP/بازیابی اعلان پایان نشست ندارد؛ پاسخ ۴۰۱ تغییر
محافظت‌شده همچنان دارد. خطا و مقدار خود فرم عمومی حفظ می‌شود، بدون آنکه نوسازی
واقعی نشست تضعیف شود.

[useOperationScope](../src/shared/hooks/use-operation-scope.ts) یک mount فعال را
برای عملیات ناهمگام ثبت می‌کند. پاکسازی effect، شامل تکرار StrictMode، آن ثبت را
برای همیشه بی‌اعتبار می‌کند. پایان دیررس پس از جایگزینی یا unmount مالک نباید
آن را تغییر دهد؛ این ابزار نوشتن API را لغو یا برعکس نمی‌کند. تغییر پذیرفته‌شدهٔ
حساب همچنان محافظ کلید مستقل provider را دارد. بررسی مقصد OTP و جلوگیری از
ارسال هم‌زمان متعلق به فرم هستند.

تغییر موفق رمز از [آداپتر محدود سند](../src/shared/navigation/document.ts) و
ناوبری دیگر قابلیت‌ها از مرز router فریم‌ورک ثبت‌شده استفاده می‌کند. تست فقط این
مرزهای ناوبری را mock می‌کند، نه کلاینت HTTP، نشست یا انتخاب پیام را.

## شمارش معکوس

[useCooldown](../src/shared/hooks/use-cooldown.ts) شمارش معکوس تلاش مجدد با بازهٔ
محدود و متناهی یک تا ۶۰۰ ثانیه دارد. ورودی نامتناهی یا NaN یک ثانیه می‌شود. شروع
دوباره timer قبلی را جایگزین و رسیدن به صفر یا unmount آن را پاک می‌کند. این هوک
مالک محدودیت OTP یا مجوز تلاش پیش از سیاست سرور نیست.

تست واقعی هوک React، تکرار effect در StrictMode، خواندن/تغییر دیررس، نشست ناشناس،
خطا و تلاش مجدد، تغییر نسل، رفت‌وبرگشت زبان، حذف رویداد، مرز شمارش و پاکسازی timer را می‌سنجد. تست فرم، عملیات در حال انتظار، تعویض حساب، ترجمهٔ محدود و بازخورد و ناوبری دیررس را نیز می‌سنجد.
درخواست‌ها کد HTTP محلی واقعی با Response مصنوعی و AbortSignal متعلق به خود دارند.
API موجود یا نشست مرورگر فراخوانی نمی‌شود. این تست مالکیت وضعیت محلی را ثابت می‌کند
و شاهد مجوز سرور یا hydration مرورگر نیست.
[پایهٔ رابط](client-ui.fa.md) و [مالکیت HTTP](client-document.fa.md) را بخوانید.
