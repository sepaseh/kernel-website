# سیاست و شواهد بازبینی امنیت

[English](reviews.md) · [فارسی](reviews.fa.md)

برای هر تغییر HTTP، ورود، نشست، artifact و پیکربندی یا مرجع استقرار، مرز تهدید و
سورس و آزمون واقعی آن بازبینی شود. محدوده را از
[نشانگر انتشار](../../.github/bootstrap-policy.json) و
[قرارداد برنامه](../application.fa.md) بگیرید. آزمون محلی، سناریوی نوشته‌شده و
قالب ایستا، سرویس امن، اسکن ارائه‌دهنده یا استقرار را ثابت نمی‌کند. پیش از
commit، push یا تحویل PR مجاز، [گیت مرجع](../validation.fa.md) کامل اجرا و شکست
audit و آزمون حفظ شود.

حذف ردهٔ فایل و رد مسیر لینک‌شده، مالکیت خروجی غیرقابل‌بازنویسی، پیکربندی عمومی
نامطمئن، اعتبارسنجی مقصد و خطای پاک‌سازی بازبینی شود. نگهبان آمادگی CLI، عملیات
برنامه و تحویل را هنگام false بودن نشانگر متوقف می‌کند؛ fixture مصنوعی که آمادگی را صریح
اعلام می‌کند، قرارداد را می‌آزماید و برنامهٔ غایب را تأیید نمی‌کند. فیلتر نام فایل
نمی‌تواند هر رمز داخل محتوای مجاز را کشف کند. dotenv واقعی، کلید، state توسعه‌دهنده،
حساب production یا bucket واقعی وارد fixture نشود.

سقف PR به‌روزرسانی نسخه در Dependabot موجود صفر می‌ماند؛ انتشار این سیاست، PR
به‌روزرسانی را فعال نمی‌کند و تنظیم امنیتی ارائه‌دهنده را ثابت نمی‌کند. فعال‌سازی
CodeQL، DAST، انتشار و staging و اجرای واقعی آن‌ها جداگانه تأیید شود. برنامه،
workflow غایب یا تعریف دستی، اسکن زمان‌بندی‌شدهٔ فعال نیست. انتشار workflow
مجوز dispatch، دسترسی production یا انتشار نسخه نیست. Sonar بومی و بررسی الزامی همچنان طبق
[سیاست شاخه](../branch-protection.fa.md) شاهد ارائه‌دهنده روی head دقیق می‌خواهند.

به‌عنوان سیاست بازبینی انسانی، فرض‌های امنیتی دست‌کم فصلی و پیش از انتشار عمومی
بازبینی شوند: سازگاری و مالکیت API، کوکی و مبدأ، CSP و cache، تمدید TLS، هویت مقصد،
بازگشت نسخه و شاهد بازیابی. این سند automation زمان‌دار ایجاد نمی‌کند و بازبینی
انجام‌شده ثبت نمی‌کند. اسکن خارجی مقصد صریح مجاز و مرز غیرproduction بازبینی‌شده
می‌خواهد. یافته و artifact حساس مطابق [SECURITY](../../SECURITY.fa.md) خصوصی بماند.
سورس واقعی، تاریخ، مالک، اجرا، شکست و محدودیت ثبت شود؛ نبود شاهد، نامعلوم می‌ماند.
[مدل تهدید](threat-model.fa.md) و [بازبینی ورود](authentication-review.fa.md) را ببینید.
