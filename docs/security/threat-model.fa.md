# مرز اعتماد وب‌سایت و ریسک باقی‌مانده

[English](threat-model.md) · [فارسی](threat-model.fa.md)

مرز اجرای هدف از مرورگر به درگاه TLS مورداعتماد، سپس آداپتر درخواست وب‌سایت و API
مستقل صریح است. [نشانگر انتشار](../../.github/bootstrap-policy.json) و موجودی دقیق،
مالک تحویل‌شده را مشخص می‌کنند. با نشانگر false، پشتیبانی محلی HTTP، نشست و CSP،
سناریوی نوشته‌شدهٔ مرورگر و قالب غیرفعال درگاه، مرز سرتاسری در حال اجرا را ثابت
نمی‌کنند. [پذیرش برنامه](../application.fa.md) اجرای درخت دقیق را لازم دارد؛
استقرار بعدی افزون بر آن، شاهد لبهٔ مورداعتماد و اپراتور خودش را می‌خواهد.

[قرارداد پراکسی](../server-boundary.fa.md) مسیر و متد، مبدأ نوشتن، هدر و بدنهٔ JSON
را محدود، کوکی متعلق به API را منتقل، فیلد شناخته‌شدهٔ توکن ورود را حذف و پاسخ
private و no-store برمی‌گرداند. آداپتر برنامه و لبه باید Host و پروتکل معتبر را حفظ
و forwarding جعلی را رد کنند. [نشست و فرم](../session.fa.md) نتیجهٔ محلی دیررس را
مهار می‌کند؛ API مستقل باید با قرارداد و شاهد خودش احراز هویت، مجوز، ماندگاری، OTP
و ابطال را اثبات کند. اینجا هیچ پیاده‌سازی API تأیید نمی‌شود.

[ابزار CSP](../website-csp.fa.md) nonce ارائه‌شده و تنظیم سیاست را اعتبارسنجی
می‌کند. تولید رمزنگارانهٔ تازه، حذف هدر جعلی، انتخاب هدر پاسخ، اتصال HTML و خروج از
cache متعلق به خط درخواست برنامه است و شاهد واقعی پاسخ و مرورگر می‌خواهد. report-only نقض را مسدود نمی‌کند. SEO و noindex مجوز
نیست و یکپارچگی فایل فونت، رندر مرورگر یا تحویل شبکه را ثابت نمی‌کند.

ابزار تحویل، مسیر، ردهٔ فایل، فیلد عمومی قالب و مالکیت نسخهٔ غیرقابل‌بازنویسی را
محدود می‌کند. نگهبان آمادگی CLI مجموعهٔ با نشانگر false را پیش از عملیات رد
می‌کند. آزمون‌ها درخت build ساختگی متعلق به خود، تنظیم عمومی و منبع loopback
دارند. قالب و فرادادهٔ مطابق، TLS سالم، رسیدگی درست رمز، وابستگی نصب‌شده، منشأ
artifact یا هویت مقصد واقعی را ثابت نمی‌کند. فیلتر نام فایل همهٔ محتوای حساس را
نمی‌یابد و کنترل واژگانی میزبان مانع alias، تغییر DNS یا redirect نیست.

ریسک باقی‌مانده شامل آسیب‌پذیری وابستگی، تفاوت مرورگر و پلتفرم، اتصال اجرای
تأییدنشده و رفتار اپراتور و API است. هر تغییر قابل اجرا به گیت واقعی برنامه و
شاهد API و مرورگر مصنوعی نیاز دارد. استقرار همچنین به بررسی لبه و TLS و بازگشت و بازبینی خصوصی یافتهٔ حساس
نیاز دارد. اینجا collector پیش‌فرض RUM و CSP یا برنامهٔ اسکن اضافه نمی‌شود.
[بازبینی ورود](authentication-review.fa.md)، [سیاست بازبینی](reviews.fa.md) و
[پذیرش استقرار](../deployment.fa.md) را دنبال کنید.
