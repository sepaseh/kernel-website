# بازبینی مرز احراز هویت

[English](authentication-review.md) · [فارسی](authentication-review.fa.md)

[نشانگر انتشار](../../.github/bootstrap-policy.json) شاهد helper با نشانگر false
را از پذیرش برنامهٔ قابل اجرا جدا می‌کند.
[ابزار forwarding API](../../src/shared/api/proxy.ts) و
[آزمون مالک](../../src/shared/api/proxy.test.ts) از Request، Response و stream
مصنوعی Web استفاده می‌کنند. این آزمون مسیر متصل، نشست واقعی API یا جداسازی
کوکی مرورگر را ثابت نمی‌کند. [قرارداد برنامه](../application.fa.md) اجرای جداگانه
روی درخت دقیق را لازم دارد. پیش از تغییر رفتار ورود، قرارداد کامل
[مرز سرور](../server-boundary.fa.md)، [نشست](../session.fa.md) و
[فرم](../forms.fa.md) را بخوانید.

allowlist مسیر و متد، مقایسهٔ دقیق Origin نوشتن، ورودی JSON محدود، timeout و لغو،
redirect دستی upstream و پاسخ عمومی خطا بازبینی شود. فقط هدر درخواست و پاسخ
اعلام‌شده از مرز می‌گذرد. پاسخ شخصی، از جمله خطا، private و no-store می‌ماند. JSON
ورود موفق فیلد شناخته‌شدهٔ bearer و refresh را بازگشتی حذف می‌کند؛ این شناسایی عمومی
اعتبارنامهٔ دلخواه نیست. Set-Cookie حفظ می‌شود، اما احراز هویت، مجوز، ویژگی کوکی،
رسیدگی رمز، OTP و ابطال نشست متعلق به API مستقل می‌ماند. نشست opaque به‌تنهایی
rotation یا تشخیص استفادهٔ دوبارهٔ refresh را ثابت نمی‌کند.

آزمون محلی نشست و فرم، مالکیت حساب، locale و generation، پاک‌سازی و feedback و
ناوبری دیررس را بررسی می‌کند. خطای ورود عمومی بازخورد فرم را حفظ و اعلان انقضای
نوشتن محافظت‌شده همچنان عمل می‌کند. این نگهبان سمت کاربر مجوز نوشتن API نیست و
نوشتن پذیرفته‌شدهٔ API را برنمی‌گرداند. فاصلهٔ دقیق رمز و مالکیت مقصد OTP حفظ شود.

پذیرش برنامه و استقرار باید با API مصنوعی مستقلِ نصب‌شده طبق
[قرارداد fixture پین‌شده](../api-fixture.fa.md)، مرز واقعی Host و پروتکل و forwarding
درگاه، ویژگی و جداسازی کوکی مرورگر، مسیرهای ورود و حساب پشتیبانی‌شده، خطا و تنظیم
دردسترس‌نبوده را بررسی کند. هدر و cache واقعی CSP و خروجی بدون افشای اعتبارنامه
تأیید شود؛ [ابزار خالص CSP](../website-csp.fa.md) آن‌ها را متصل نمی‌کند. دسترسی
راه‌دور یا production مجوز جدا می‌خواهد. سورس دقیق، fixture API، پلتفرم، شکست و
محدودیت در [آزمون](../testing.fa.md) ثبت و
[گزارش خصوصی](../../SECURITY.fa.md) رعایت شود.
