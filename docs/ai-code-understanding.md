# Source understanding

[English](ai-code-understanding.md) · [فارسی](ai-code-understanding.fa.md)

Start with local search, [AGENTS](../AGENTS.md) and the task's owners, contracts,
rules and tests in [navigation](../.agents/navigation.json). Read complete owning
functions and trace inputs, errors, HTTP compatibility, sessions, cache privacy,
language and source freshness. Optional assistants and indexes are not runtime
dependencies.

The [evaluation guide](comprehension-evaluation.md) separates path/instruction
checks, observed instruction discovery and answer quality. Keep proposed tools,
executed measurements and unknowns separate. An index or external upload needs an
actual purpose, an explicit data scope and authorization for the external action.
No provider is required for ordinary source work.

This phase's navigation contains only published support, feature and guidance
owners. An accepted future runtime design is not current runnable source. Verify
the exact snapshot before answering, and state when build, browser or deployment
evidence is absent.
