## انتخاب صاحب آزمون

[آزمون API](../scripts/api-repository.test.mjs)، [ابزار کارایی](../scripts/website-performance.test.mjs) و [ابزار تصویر](../scripts/visual-environment.test.mjs) پروژهٔ مصنوعی دورریختنی دارند. صاحبان تحویل شامل [سیاست فایل](../scripts/release-files.test.mjs)، [آماده‌سازی](../scripts/prepare-standalone.test.mjs)، [بسته‌بندی](../scripts/package-release.test.mjs)، [تنظیم و سلامت](../scripts/deployment.test.mjs)، [پاک‌سازی](../scripts/docker-smoke-cleanup.test.mjs) و [مقصد](../scripts/validate-workflow-targets.test.mjs) هستند. [آزمون audit](../scripts/run-audit.test.mjs) صاحب واحد و mock زیرفرایند رجیستری را حفظ می‌کند.

راهنمای [راه‌انداز](runner-foundation.fa.md) و [مرورگر](browser-foundation.fa.md) موارد Node اندازه‌گیری‌شده را نگاشت می‌کند. import بی‌اثر می‌ماند؛ ورودی اصلی با نشانگر false پیش از تنظیم، وابستگی، شبکه یا فایل خروجی رد می‌شود. فقط ریشهٔ مصنوعی متعلق به آزمون برای مسیر مثبت محافظ می‌تواند آمادگی اعلام کند. لغو، شکست، خروجی محدود و پاک‌سازی شیء فرزند مستقیمی را که صاحب ساخته بیازمایید.

[fixture API](api-fixture.fa.md) انتخاب مطلق صریح، نسخهٔ عمومی تثبیت‌شدهٔ Git، سورس پاک، وابستگی مستقل نصب‌شده و ورودی منتشرشده می‌خواهد. نشانگر ساختاری کافی نیست. Git سیستمی ثابت استاندارد، فهرست مجاز سخت‌گیرانهٔ محیط و مالکیت درگاه والد و فرزند حفظ شود. آزمون مالک Node از fixture متعلق به خود و Git ساختگی استفاده می‌کند؛ بررسی مرورگر برنامه جداگانه API مستقل نصب‌شده را با داده و راز تازهٔ صرفاً آزمایشی بیرون سورس و هویت تأییدشدهٔ مرورگر اجرا می‌کند.

## ثبت نتیجه

درخت و نسخهٔ دقیق، فرمان، اولین شکست، نتیجه، شکست و مورد ردشده، پوشش و پاک‌سازی متعلق به خود را ثبت و [پایداری آزمون](test-reliability.fa.md) را دنبال کنید. همهٔ منبع محصول اندازه‌گیری شود؛ آستانهٔ ۹۰٪ واحد، ۸۰٪ راهبری و پوشش واقعی فونت حفظ شود. بررسی کوچک یا گزارش سبز قدیمی درخت انتشار دیگر را اعتبارسنجی نمی‌کند.

آزمون محلی، اجرای مرورگر، بازبینی بصری دستی، بررسی میزبانی‌شده و تاریخچه شواهد جدا هستند. نشانگر true یا مسیر تألیف‌شده هیچ‌یک را ثابت نمی‌کند. پذیرش کامل قابل اجرا هر پانزده بررسی و کارهای واقعی محافظت‌شدهٔ build/e2e/visual پیش از ادغام می‌خواهد. این شاهد OTP تولید، استقرار، انطباق کامل دسترس‌پذیری یا کارایی میدانی نیست.
