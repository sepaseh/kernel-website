# پایهٔ مؤلفه‌های محلی کلاینت

[English](client-ui.md) · [فارسی](client-ui.fa.md)

[مرحلهٔ client-ui](bootstrap.fa.md) سیزده ماژول مستقل قابل‌آزمون اضافه می‌کند: پنج
ابزار محلی shadcn/Radix، FormField و Feedback، provider نشست و پوسته/حرکت، ترجیح
پوسته، شمارش معکوس محدود، Reveal و آداپتر هوک Web Vitals. صفحه، layout ریشه، ساخت
CSS، آداپتر درخواست Next.js یا وب‌سایت قابل اجرا وجود ندارد. تا عبور بررسی‌های واقعی
برنامه، applicationReady:false حفظ شود.

## مؤلفه‌ها و سبک

ابزارهای محلی src/components/ui از Slot/Label مربوط به Radix، کتابخانهٔ
class-variance-authority و ابزار موجود clsx/tailwind-merge استفاده می‌کنند. ویژگی
بومی ورودی و دکمه، رفتار disabled، معنای فرزند Slot و کلاس مصرف‌کننده حفظ شود.
ورودی مؤلفه تایپ مستقیم دارد و lint استفاده از React.FC/FunctionComponent را رد
می‌کند. واردسازی بسته و تایپ/اجرای آن برای هر مالک صریح و محدود است.

دکمهٔ بومی Button به‌صورت پیش‌فرض type="button" دارد تا فرم ناخواسته ارسال نشود.
دکمهٔ ارسال باید type="submit" را صریح بدهد؛ asChild رفتار نوع عنصر فرزند را تغییر
نمی‌دهد.

FormField با id صریح یا شناسهٔ تولیدی React برچسب را به ورودی وصل می‌کند؛ name مستقل است و لازم نیست در کل سند یکتا باشد.
شناسهٔ تولیدی ورودی‌های بی‌نام را متمایز نگه می‌دارد. خطا بر راهنما اولویت دارد و
شناسهٔ توضیح آن با aria-describedby مصرف‌کننده ترکیب می‌شود. Feedback محتوای
ترجمه‌شدهٔ واقعی alert/status را نشان می‌دهد، متن API را با React escape می‌کند و
برای خطای انتقال/سرور پیام عمومی شبکه می‌دهد. آیکون Lucide واردسازی نام‌دار مستقیم،
اندازه و currentColor صریح و aria-hidden تزئینی دارد. درج پیام HTML مجاز نیست.

رشتهٔ کلاس Tailwind و معنای مؤلفه منتشر شده‌اند؛ stylesheet و خط ساخت CSS تولید
هنوز نیستند. تست DOM و متن ثابت، چیدمان، کنتراست، مسیر صفحه‌کلید یا انطباق کامل
دسترس‌پذیری مرورگر را ثابت نمی‌کند.

## پوسته، حرکت و معیارها

Preferences فقط پوسته را با next-themes نصب‌شده تغییر می‌دهد. provider ترکیبی از
کلاس dark/light، راه‌اندازی ثابت تیره، بدون انتخاب پوستهٔ سیستم و ذخیرهٔ
kernel-website-theme استفاده می‌کند. این ترجیح زبان را انتخاب نمی‌کند؛ تنظیمات
API مرجع هستند. اسکریپت پوسته nonce داده‌شدهٔ CSP را در متن ثابت سرور می‌گیرد.
اتصال واقعی nonce و درخواست Next.js هنوز منتشر نشده است.

Reveal مؤلفهٔ حداقلی strict از Motion است و محتوای اولیه را مرئی نگه می‌دارد.
کاهش حرکت، جابه‌جایی اولیه و تأخیر حرکت را حذف می‌کند. provider ترکیبی سیاست کاهش
حرکت کاربر را منتقل می‌کند. تست متن ثابت React این رفتار محلی را می‌سنجد و شاهد
hydration فریم‌ورک یا حرکت و بارگذاری مرورگر نیست.

WebVitals فقط callback پایدار و خصوصی گزارش را در هوک Next ثبت می‌کند و رابط
ندارد. تست مالک ثبت callback را می‌سنجد؛ جمع‌آوری واقعی معیار مرورگر متعلق به
برنامهٔ قابل اجراست. انتقال پیش‌فرض telemetry نداریم. snapshot مشترکان و کنترل
حریم خصوصی موجود حفظ شود.

## اعتبارسنجی

تست واقعی React Testing Library با React، Radix، next-intl و ابزار پوستهٔ نصب‌شده
در jsdom جداگانه، معنای Slot/disabled، رویداد بومی ورودی، پیوند برچسب و توضیح،
پیام امن ترجمه‌شده و ذخیرهٔ صرفاً پوسته را بررسی می‌کند. تست متن ثابت Node مرئی بودن
محتوا، ترکیب provider و nonce را می‌سنجد. media-query مصنوعی فقط ابزار تست است.
همهٔ ماژول‌های اجرایی تولید در پوشش واقعی و تحلیل Sonar می‌مانند. قواعد توصیه‌شدهٔ
هوک به همان lint الزامی افزوده شده‌اند؛ هر ده بررسی مرجع، صحت فونت و حداقل‌های
پوشش قبلی الزامی‌اند.

[مالکیت نشست و شمارش معکوس](session.fa.md)،
[پشتیبانی کلاینت و سند](client-document.fa.md) و
[مشارکت](../CONTRIBUTING.fa.md) را بخوانید. پیش از انتشار قابل اجرا، هر پانزده
بررسی برنامه و کار واقعی و الزامی build/e2e/visual با fixture مصنوعی API مستقل
نصب‌شده اضافه شود.
