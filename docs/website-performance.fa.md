# ابزار کارایی و مرز اندازه‌گیری

[English](website-performance.md) · [فارسی](website-performance.fa.md)

ابزار bundle و محیط، اجراکنندهٔ فرایند و تحلیلگر با کنترل آمادگی پیش از عملیات،
و سناریوی نوشته‌شدهٔ مرورگر سورس نگه‌داری‌شده‌اند.
[نشانگر انتشار](../.github/bootstrap-policy.json) مشخص می‌کند موجودی دقیق، ترکیب
برنامه را دارد یا نه. در حالت `applicationReady:false` این ابزار ساخت production،
اندازه‌گیری مرورگر، اجرای Lighthouse یا دادهٔ میدانی را ثابت نمی‌کند.
[پذیرش برنامه](application.fa.md) شاهد واقعی ساخت، بودجه و مرورگر می‌خواهد؛ تحلیل
اختیاری آزمایشگاهی و میدانی شاهد و مجوز خودش را دارد. انتقال خارجی پیش‌فرض معیار وجود ندارد.

## ابزار منتشرشده

[check-bundle-website](../scripts/check-bundle-website.mjs)، manifest کلاینت
پشتیبانی‌شدهٔ Next را به‌صورت دادهٔ JSON parse می‌کند، نه کد تولیدشدهٔ اجرایی.
با پوشهٔ ساخت صریح، JS و CSS مرورگر تولیدشده و گراف قابل دسترس هر صفحه را
می‌سنجد و دارایی مشترک را در هر مسیر یک بار می‌شمرد. دادهٔ پشتیبانی‌نشده،
مسیر ناامن، دارایی غایب و اندازه‌گیری نامعتبر باید خطای صریح بدهند.
[آزمون مالک](../scripts/website-performance.test.mjs) از فایل ساخت مصنوعی
و مرز بودجه استفاده می‌کند، نه ساخت واقعی Next.

گراف قابل دسترس کلاینت شامل runtime مشترک، polyfill و chunk احتمالی مرز است.
انتقال اولیهٔ شبکه، JavaScript اجراشده یا استفادهٔ میدانی نیست. اندازهٔ gzip
جمع فایل‌های جداگانهٔ فشرده‌شده است و encoding واقعی میزبان را ثابت نمی‌کند.
[performance-budget.json](../performance-budget.json) مالک حدود است: سقف
رگرسیون‌اند، نه هدف سرویس اندازه‌گیری‌شده. پیش از تغییر حد، شاهد واقعی و سازگار
را بررسی کنید.

[ساخت محیط](../scripts/website-performance-environment.mjs) مبدأ API
loopback و IPv4 جداگانه با پورت صریح غیرصفر می‌خواهد و محیط فرزند مصنوعی را با فهرست مجاز می‌سازد.
بررسی تمیزی وب‌سایت، وجود dotenv مرتبط را بدون بارگذاری، جابه‌جایی یا بازنویسی
مقدار می‌سنجد. helper فرایند راه نمی‌اندازد و نصب API را ثابت نمی‌کند.
[محل API](../scripts/api-repository.mjs) به KERNEL_SYNTHETIC_ENV=1 و
KERNEL_API_DIRECTORY مطلق صریح نیاز دارد؛ [آداپتر fixture](api-fixture.fa.md)
افزون بر آن revision عمومی تغییرناپذیر، سورس تمیز و هویت وابستگی مستقل نصب‌شده
را می‌سنجد. این بررسی با اجرای واقعی API و مرورگر متفاوت است.

## پشتیبانی سورس حفظ‌شده

[WebVitals](../src/shared/performance/WebVitals.tsx) callback پایدار را به هوک
فریم‌ورک می‌دهد؛ آزمون مالک آن مرز را mock می‌کند.
[helper تحویل](../src/shared/performance/web-vitals.ts) فقط فیلد عددی استاندارد
مجاز را به مصرف‌کنندهٔ صریحاً مشترک‌شده می‌دهد؛ انتقال، ذخیره یا replay
پیش‌فرض ندارد. شکست مصرف‌کننده، تحویل دیگری را خراب نمی‌کند. callback و تست مالک
دارای mock به‌تنهایی اتصال layout ریشه، سرویس RUM فعال، INP میدانی یا مجموعهٔ
دادهٔ p75 را ثابت نمی‌کنند. مقدار متوالی
معیار را جمع و معیار تعامل غایب را صفر فرض نکنید.

[انتخاب پیام کلاینت](../src/i18n/client-messages.ts) کلید صریح و محدود را
حفظ می‌کند. [صحت فونت](fonts.fa.md)، باینری واقعی منبع و زیرمجموعه، مجوز،
هش و metadata را می‌سنجد و سیاست preload زبان را نگه می‌دارد. این helperها
انتقال مرورگر، شکل‌دهی، CSS محاسبه‌شده یا کارایی نمایش صفحه را ثابت نمی‌کنند.

## شواهد برنامه و اندازه‌گیری

پیش از اجرای build و bundle، مرورگر، شکل‌دهی فونت، Lighthouse یا analyzer،
موجودی واقعی برنامه و [API مصنوعی پین‌شده](api-fixture.fa.md) مستقل نصب‌شده
را الزامی کنید. وجود یک اجراکننده، عملیات منتشرنشده را فعال نمی‌کند. دادهٔ موقت
متعلق به آزمون، محیط با فهرست مجاز و مقصد صرفاً loopback به‌کار رود؛ خروجی
ساخت مشترک به‌ترتیب مصرف و فقط منبع متعلق به آزمون پاک شود. سورس و build
دقیق، نسخهٔ ابزار و مرورگر، تنظیم، تمام نمونه‌ها، شکست و پاک‌سازی را ثبت کنید.

مشاهدهٔ آزمایشگاهی را از معیار میدانی، و امتیاز توصیه‌ای را از شکست الزامی
درستی و بودجه جدا کنید. برای بهبود امتیاز، محتوا را پنهان، کار را پس از پنجرهٔ
audit موکول، رفتار واقعی نشست را حذف یا baseline را تازه نکنید. گراف analyzer
خودش اندازهٔ انتقال و کارایی نیست. [آزمون](testing.fa.md)،
[رگرسیون تصویری](visual-regression.fa.md) و [اعتبارسنجی مرجع](validation.fa.md)
را رعایت کنید. این راهنما هیچ موفقیت فعلی مرورگر یا کارایی را ثبت نمی‌کند.
