# پشتیبانی کلاینت و سند

[English](client-document.md) · [فارسی](client-document.fa.md)

این مرحله ابزارهای مستقل قابل تست برای وب‌سایت آینده را آماده می‌کند. نقطهٔ ورود برنامه، مسیر یا آداپتر سرور Next.js، رابط یا fixture مرورگر منتشر نمی‌شود و applicationReady:false باقی است.

## مالکیت HTTP

کلاینت مشترک مسیر هم‌مبدأ /api را با credentials:include و cache:no-store فراخوانی، هدر ورودی را کپی و زبان منتخب API را منتقل می‌کند. proxy موجود ترجیح زبان بازدیدکننده را پیش از API مستقل حذف می‌کند. پنج ماژول API قابلیت‌ها از این کلاینت مشترک استفاده می‌کنند و مالک دوازده عملیات و payload به شکل snake_case هستند. فاصلهٔ رمز عبور و لغو فراخواننده حفظ می‌شود. توکن یا زبان محلی ذخیره نمی‌شود.

پاسخ موفق خالی undefined می‌دهد و JSON موفق نامعتبر خطا دارد. envelope خطا، پیام محلی‌شده، خطای رشته‌ای فیلد و شناسهٔ درخواست را نگه می‌دارد؛ JSON نامعتبر یا غیرشیء پیام عمومی امن می‌دهد. خطای fetch یا جریان پاسخ، از جمله لغو پس از هدر، هویت اصلی خود را حفظ می‌کند. 401 کامل مسیر محافظت‌شده یک اعلان پایان جلسه می‌فرستد؛ خواندن ناشناس /account/me و بدنهٔ لغوشده اعلان ندارند.

## دادهٔ سند و ترجمه

SEO نشانی صریح WEBSITE_URL و پرچم بولی دقیق را از محیط ورودی می‌خواند. فعال شدن نمایه‌سازی به production و مبدأ HTTPS غیرloopback نیاز دارد و پیش‌فرض خاموش است. متادیتا مسیر معتبر صفحه، canonical همان صفحه و عنوان و توضیح ترجمه‌شده دارد؛ اینجا HTML تولید نمی‌شود. JSON-LD همهٔ نویسه‌های کمتر از را escape می‌کند تا مقدار نتواند عنصر script بعدی را ببندد.

next-intl نصب‌شده هر ۱۰۷ پیام تمام زبان‌های ثبت‌شده را parse و interpolate می‌کند. انتخاب پیام root/auth/account فقط کلید تخت صریح خود و کلید مشترک لازم را نگه می‌دارد و مقدار مفقود یا تودرتو را رد می‌کند. آداپتر درخواست یا provider مربوط به Next.js وارد نشده است؛ [ترجمه](localization.fa.md) را بخوانید.

Web Vitals فقط فیلد عددی استاندارد مجاز را به مصرف‌کنندهٔ مشترک‌شدهٔ صریح می‌دهد؛ گزارش ذخیره یا انتقال پیش‌فرض ندارد. خطای یک مصرف‌کننده دیگری را متوقف نمی‌کند و تحویل روی snapshot است تا لغو و اشتراک دوباره در همان اعلان حلقه نسازد. import نوع Metadata و Web Vitals از Next حذف‌شونده است. React و React DOM وابستگی peer فریم‌ورک و ICU را کامل می‌کنند؛ کامپوننت React منتشر نشده است.

ابزار کلاس از clsx و tailwind-merge واقعی استفاده می‌کند. [فونت](fonts.fa.md) منبع دارای مجوز، بررسی باینری و انتخاب preload زبان فعال را شرح می‌دهد.

## شواهد و کار باقی‌مانده

تست Node با Request، Response و جریان واقعی و کتابخانهٔ نصب‌شده، fetch مصنوعی را می‌سنجد: دوازده عملیات، cache/cookie/signal، خطای بدنه و envelope، ICU همهٔ زبان‌ها، رد و escape در SEO، حریم خصوصی و تحویل معیار و صحت فونت. تست مرز، مالک دقیق بسته، هویت بسته و نوعی یا اجرایی بودن import را می‌خواهد؛ قرارداد و دادهٔ کاتالوگ خالص می‌مانند.

[گیت کامل](../.agents/validation.json) ده بررسی شامل صحت واقعی فونت و پوشش Python دارد. رفتار بازبینی‌شدهٔ proxy، CSP، تنظیمات و کاتالوگ، حداقل واحد ۹۰٪، گردش‌کار ۸۰٪ و استثنای تکرار محدود به ده کاتالوگ حفظ می‌شوند.

متادیتای SSR، nonce درخواست، مسیر فریم‌ورک، کامپوننت، شکل‌دهی و بارگذاری فونت مرورگر، سفر جلسه، دسترس‌پذیری و تصویر مرجع متعلق به مراحل بعد هستند. پیش از انتشار قابل اجرا هر پانزده بررسی برنامه و job واقعی الزامی build/e2e/visual را با fixture مصنوعی API مستقل اضافه کنید. این شواهد مرحلهٔ پشتیبان، رفتار مرورگر یا استقرار را ثابت نمی‌کنند.
