# پشتیبانی کلاینت و سند

[English](client-document.md) · [فارسی](client-document.fa.md)

این راهنما قرارداد پشتیبانی HTTP و سند را در مجموعهٔ پیش‌نیاز و برنامه تعریف می‌کند. [نشانگر انتشار](../.github/bootstrap-policy.json) و [راهنمای مرحله](bootstrap.fa.md) محدودهٔ تحویل‌شده را تعیین می‌کنند. در حالت `applicationReady:false`، [فرم](forms.fa.md)، provider، آزمون نوشته‌شدهٔ مرورگر و محافظ fixture، اتصال مسیر Next.js، خط ساخت CSS یا اجرای واقعی مرورگر را ثابت نمی‌کنند. [قرارداد برنامه](application.fa.md) ترکیب و شواهد افزودهٔ لازم برای فعال‌سازی را مشخص می‌کند.

## مالکیت HTTP

کلاینت مشترک مسیر هم‌مبدأ /api را با credentials:include و cache:no-store فراخوانی، هدر ورودی را کپی و زبان منتخب API را منتقل می‌کند. proxy موجود ترجیح زبان بازدیدکننده را پیش از API مستقل حذف می‌کند. پنج ماژول API قابلیت‌ها از این کلاینت مشترک استفاده می‌کنند و مالک دوازده عملیات و payload به شکل snake_case هستند. فاصلهٔ رمز عبور و لغو فراخواننده حفظ می‌شود. توکن یا زبان محلی ذخیره نمی‌شود.

پاسخ موفق خالی undefined می‌دهد و JSON موفق نامعتبر خطا دارد. envelope خطا، پیام محلی‌شده، خطای رشته‌ای فیلد و شناسهٔ درخواست را نگه می‌دارد؛ JSON نامعتبر یا غیرشیء پیام عمومی امن می‌دهد. خطای fetch یا جریان پاسخ، از جمله لغو پس از هدر، هویت اصلی خود را حفظ می‌کند. ۴۰۱ کاملِ تغییر محافظت‌شده یک اعلان پایان جلسه می‌فرستد؛ خواندن ناشناس /account/me، عملیات عمومی ورود/ثبت‌نام/OTP/بازیابی و بدنهٔ لغوشده اعلان ندارند تا خطای احراز هویت عمومی بازخورد فرم خودش را حفظ کند.

## دادهٔ سند و ترجمه

SEO نشانی صریح WEBSITE_URL و پرچم بولی دقیق را از محیط ورودی می‌خواند. فعال شدن نمایه‌سازی به production و مبدأ HTTPS غیرloopback نیاز دارد و پیش‌فرض خاموش است. متادیتا مسیر معتبر صفحه، canonical همان صفحه و عنوان و توضیح ترجمه‌شده دارد؛ اینجا HTML تولید نمی‌شود. JSON-LD همهٔ نویسه‌های کمتر از را escape می‌کند تا مقدار نتواند عنصر script بعدی را ببندد.

next-intl نصب‌شده هر ۱۰۷ پیام تمام زبان‌های ثبت‌شده را parse و interpolate می‌کند. انتخاب پیام root/auth/account فقط کلید تخت صریح خود و کلید مشترک لازم را نگه می‌دارد و مقدار مفقود یا تودرتو را رد می‌کند. تست فرم قابلیت از provider واقعی next-intl و انتخاب صریح پیام auth/account استفاده می‌کند. اتصال Next.js وابسته به درخواست و provider ریشه باید همین انتخاب را حفظ کند و در مجموعهٔ برنامه سنجیده شود؛ آزمون helper به‌تنهایی این اتصال را اجرا نمی‌کند. [ترجمه](localization.fa.md) را بخوانید.

Web Vitals فقط فیلد عددی استاندارد مجاز را به مصرف‌کنندهٔ مشترک‌شدهٔ صریح می‌دهد؛ گزارش ذخیره یا انتقال پیش‌فرض ندارد. خطای یک مصرف‌کننده دیگری را متوقف نمی‌کند و تحویل روی snapshot است تا لغو و اشتراک دوباره در همان اعلان حلقه نسازد. import نوع Web Vitals این ابزار تحویل و Metadata از Next حذف‌شونده است. [مؤلفهٔ WebVitals](client-ui.fa.md) جداگانه callback پایدار را به هوک اجرایی Next می‌دهد؛ تست مالک دارای mock، جمع‌آوری معیار مرورگر را ثابت نمی‌کند.

ابزار کلاس از clsx و tailwind-merge واقعی استفاده می‌کند. [فونت](fonts.fa.md) منبع دارای مجوز، بررسی باینری و انتخاب preload زبان فعال را شرح می‌دهد.

## شواهد و کار باقی‌مانده

تست Node با Request، Response و جریان واقعی و کتابخانهٔ نصب‌شده، fetch مصنوعی را می‌سنجد: دوازده عملیات، cache/cookie/signal، خطای بدنه و envelope، ICU همهٔ زبان‌ها، رد و escape در SEO، حریم خصوصی و تحویل معیار و صحت فونت. تست مرز، مالک دقیق بسته، هویت بسته و نوعی یا اجرایی بودن import را می‌خواهد؛ قرارداد و دادهٔ کاتالوگ خالص می‌مانند.

[گیت کامل مرجع](../.agents/validation.json) شامل صحت واقعی فونت و پوشش Python است. پروفایل پیش‌نیاز با نشانگر false یازده بررسی دارد و برای فعال‌سازی برنامه به هر پانزده بررسی گسترش می‌یابد. رفتار بازبینی‌شدهٔ proxy، CSP، تنظیمات و کاتالوگ، حداقل واحد ۹۰٪، گردش‌کار ۸۰٪ و استثنای تکرار محدود به ده کاتالوگ حفظ می‌شوند.

متادیتای SSR، nonce درخواست، مسیر فریم‌ورک، صفحهٔ دارای سبک، شکل‌دهی و بارگذاری فونت مرورگر، سفر نشست، دسترس‌پذیری و مقایسهٔ تصویر متعلق به پذیرش برنامه‌اند. تست محلی [رابط](client-ui.fa.md) و [نشست](session.fa.md) مرز مستند وضعیت و DOM خود را می‌سنجد. هر پانزده بررسی برنامه و job واقعی build/e2e/visual را با [API مصنوعی مستقل و پین‌شده](api-fixture.fa.md) اجرا و پیش از ادغام قابل اجرا الزامی کنید. شاهد دقیق سورس و build حفظ شود؛ نتیجهٔ مرحلهٔ پشتیبان، درخت متفاوت برنامه یا استقرار را تأیید نمی‌کند.
