# معماری وب‌سایت

[English](architecture.md) · [فارسی](architecture.fa.md)

این پروژه یک بستهٔ TypeScript مستقل قابل نصب در ریشه است. [نشانگر سورس](../.github/bootstrap-policy.json) ترکیب تحویل‌شده و موجودی دقیق و [محدودهٔ مرحله](bootstrap.fa.md) مرز برنامه را مشخص می‌کند. Next App Router جهت زمان اجرای [تصمیم۰۰۰۱](adr/0001-independent-runtimes.fa.md) را پیاده می‌کند. [یکپارچه‌سازی برنامه](application.fa.md) چیدمان ریشه، صفحه‌ها، مبدل درخواست و پوسته را به قرارداد کامل پذیرش نگاشت می‌کند.

API مستقل مالک احراز هویت و مجوز، رمز، ارسال OTP، migration پایگاه، ماندگاری و ذخیره‌سازی است. HTTP را بدون import مخزن دیگر یا بستهٔ منبع محلی مصرف کنید. تغییر ناسازگار مسیر، DTO، کوکی یا تنظیم هماهنگ شود. DTO محلی به‌تنهایی سازگاری API منتشرشده را ثابت نمی‌کند.

## وضعیت، حریم خصوصی و زبان

[SessionProvider](../src/features/auth/SessionProvider.tsx) خواندن را با زبان و نسل کلید می‌زند. refresh یا تعویض زبان snapshot قبلی را نامعتبر می‌کند؛ خواندن قدیمی و mutation پذیرفته‌شدهٔ دیررس حساب فعلی را جایگزین نمی‌کنند. فرم با نسل، زبان و شناسهٔ حساب بازنشانی می‌شود. مالکیت عملیات mount از بازخورد و راهبری دیررس جلوگیری می‌کند ولی mutation پایان‌یافتهٔ سرور را بازنمی‌گرداند. [نشست](session.fa.md) و [فرم](forms.fa.md) را بخوانید.

HTTP خطای اصلی انتقال و لغو را حفظ می‌کند. 401 احراز هویت عمومی در فرم می‌ماند و 401 mutation محافظت‌شده انقضا را اعلام می‌کند. انتقال، مسیر و روش، مبدأ تغییر و JSON محدود را اعتبارسنجی، کوکی بومی را حفظ، فیلد اعتبارنامهٔ موفق را حذف و پاسخ private/no-store تولید می‌کند. [مرز سرور](server-boundary.fa.md) را ببینید.

فقط تنظیم عمومی API بدون کش کاتالوگ پشتیبانی‌شده و جهت دقیق ltr/rtl را بدون کوکی یا مذاکرهٔ بازدیدکننده انتخاب می‌کند. هر کاتالوگ همنام زبان یک شیء رشته‌ای تخت با کلید مشترک پایه و پیشوند صریح قابلیت است و alias یا فضای نام تو‌در‌تو ندارد. پوسته مستقل است. [بومی‌سازی](localization.fa.md) تعهد آداپتور را تعیین می‌کند.

فونت، CSP، SEO، تنظیم، HTTP و سنجه حتی با یک مصرف‌کنندهٔ ترکیب صاحب معنایی زیرساخت خود را حفظ می‌کنند. Reveal متعلق به website/home و Preferences نمایش مشترک است. مسیر یا layout تازه انتقال رفتار دامنه به ترکیب یا کد سرور به export کلاینت را توجیه نمی‌کند.

## ابزار و شواهد یکپارچه‌سازی

ابزار کیفیت مسیر fixture، تحلیل بسته، محیط و فراداده و قفل را بیرون زمان اجرای محصول نگه می‌دارد. [تحویل](deployment.fa.md) و [عملیات](release-operations.fa.md) قرارداد فایل، تنظیم، سلامت و پاک‌سازی متعلق به خود و قالب غیرفعال را تعریف می‌کنند. قرارداد [راه‌انداز](runner-foundation.fa.md)، [مرورگر](browser-foundation.fa.md) و [fixture API](api-fixture.fa.md) import بی‌اثر، محافظ آمادگی پیش از عملیات، ورودی صریح و چرخهٔ متعلق به خود می‌خواهد. fixture Node و آزمون callback آمادگی واقعی API، مرورگر یا کانتینر نیست.

[فهرست مرجع](../.agents/validation.json)، [مشارکت](../CONTRIBUTING.fa.md) و [قرارداد برنامه](application.fa.md) منبع را به بررسی متصل می‌کنند. ترکیب قابل اجرا باید هر پانزده بررسی، شاهد واقعی ساخت، مرورگر، CSP و تصویر و کار محافظت‌شده را پیش از ادغام تحویل دهد. تصمیم و QA تاریخ‌دار تاریخچه است؛ نشانگر یا موفقیت ابزار جای اجرا را نمی‌گیرد.
