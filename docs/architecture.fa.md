# معماری وب‌سایت

[English](architecture.md) · [فارسی](architecture.fa.md)

مرحلهٔ پایهٔ مرورگر (`browser-foundation`) یک بستهٔ مستقل TypeScript در ریشه، پشتیبانی محلی قابلیت و UI و
دستورهای نگه‌داری‌شدهٔ آن را منتشر می‌کند. برنامهٔ Next.js قابل اجرا نیست:
مسیرها، layout ریشه، adapter درخواست، CSS سراسری، fixture مرورگر و استقرار به
بعد موکول‌اند. جهت پذیرفته‌شدهٔ runtime همچنان Next App Router است؛
[تصمیم ۰۰۰۱](adr/0001-independent-runtimes.fa.md) این تصمیم را از یکپارچه‌سازی
تحویل‌شده جدا می‌کند.

ورود، مجوز، نگه‌داری رمز، ارسال OTP، migration پایگاه، ماندگاری و ذخیره‌سازی با
API مستقل است. آن را از HTTP مصرف کنید؛ checkout دیگر یا بستهٔ سورس محلی را
import نکنید. نوع محلی به‌تنهایی سازگاری با API منتشرشده را ثابت نمی‌کند. تغییر
ناسازگار مسیر، DTO، کوکی یا تنظیمات را پیش از انتشار هماهنگ کنید.

## مرز وضعیت و حریم خصوصی

[SessionProvider](../src/features/auth/SessionProvider.tsx) خواندن را با زبان و
نسل نشست کلیدگذاری می‌کند. refresh یا تعویض زبان فوراً snapshot بارگذاری‌شدهٔ
قبلی را بی‌اعتبار می‌کند؛ خواندن لغوشده و ویرایش پذیرفته‌شدهٔ قدیمی نمی‌تواند
حساب فعلی را جایگزین کند. حالت محلی فرم نیز با نسل، زبان و هویت حساب کلیدگذاری
می‌شود. guard عملیات mount از بازخورد یا هدایت دیرهنگام پس از جایگزینی جلوگیری
می‌کند. [نشست](session.fa.md) و [فرم‌ها](forms.fa.md) رفتار و آزمون را توضیح
می‌دهند؛ guard نمی‌تواند نوشتن تکمیل‌شدهٔ سرور را برگرداند.

کلاینت HTTP خطای اصلی انتقال و لغو را حفظ می‌کند. پاسخ 401 ورود عمومی بازخورد فرم
خود را بدون اعلان انقضای نشست نگه می‌دارد؛ 401 نوشتن محافظت‌شده همچنان به provider
نشست اطلاع می‌دهد. پشتیبانی پراکسی جفت مسیر و روش مجاز، Origin نوشتن و بدنهٔ JSON
محدود را بررسی، پاسخ کوکی بومی را حفظ، فیلد اعتبارنامهٔ پاسخ موفق ورود را حذف و
پاسخ را private/no-store می‌کند. [مرز سرور](server-boundary.fa.md) را بخوانید.

## زبان، مالکیت و یکپارچه‌سازی بعدی

فقط تنظیم API کد کاتالوگ پشتیبانی‌شده و جهت معتبر را انتخاب می‌کند. بارگذار کوکی
یا ترجیح زبان بازدیدکننده را منتقل نمی‌کند و no-store دارد. هر کاتالوگ با نام کد
زبان یک شیء تخت رشته‌ای با کلید مشترک ساده و پیشوند صریح قابلیت است؛ namespace
تودرتو، alias یا کاتالوگ موازی اضافه نمی‌شود. [ترجمه](localization.fa.md) را بخوانید.

Reveal و آزمون آن زیر website/home قرار دارند. Preferences پشتیبانی نمایش مشترک
برای پوستهٔ آینده است. قلم، CSP، SEO، زبان، انتقال API و Web Vitals مالک معنایی
زیرساخت خود را نگه می‌دارند، حتی اگر فقط یک bootstrap آن‌ها را مصرف کند. ترجیح تم
از زبان مستقل است.

[تصمیم‌ها](adr/README.fa.md) مرز پذیرفته‌شده را ثبت می‌کنند.
[manifest مرجع](../.agents/validation.json)، [راهنمای مرحله](bootstrap.fa.md) و
[سیاست مشارکت](../CONTRIBUTING.fa.md) بررسی فعلی را تعیین می‌کنند. یکپارچه‌سازی
قابل اجرای آینده به شاهد واقعی build، مرورگر و CSP، بصری، SSR و استقرار نیاز دارد؛
آزمون پشتیبان و بررسی ایستای راهنما آن را ثابت نمی‌کند.

## ابزار مستقل کیفیت

چهار ابزار مستقل زیر scripts، تعیین مسیر fixture آزمون، اندازه‌گیری بستهٔ مصنوعی، ساخت محیط و فراداده و قفل بصری را خارج از ماژول محصول نگه می‌دارند. سه فایل آزمون مالک آن‌ها در Node از پروژهٔ موقت متعلق به خود استفاده می‌کنند؛ سورس محصول تغییر نمی‌کند. checkout دیگر وابستگی سورس واردشده نیست و این مرحله فرایند API، مرورگر یا استقرار را اجرا نمی‌کند. [آزمون](testing.fa.md) و [اعتبارسنجی](validation.fa.md) شواهد واقعی و پذیرش موکول‌شده را شرح می‌دهند.

## مرز آماده‌سازی تحویل

هشت ابزار Node تحویل مالک تنظیم عمومی، بررسی آمادگی صریح، سیاست فایل و آرشیو، بسته‌بندی، پاک‌سازی و اعتبارسنجی مقصد هستند. شش فایل آزمون مالک آن‌ها با درخت مصنوعی متعلق به خود، callback تزریق‌شدهٔ Docker و سرور سلامت loopback متعلق به آزمون کار می‌کند. قالب اپراتور غیرفعال باقی می‌ماند. مرحلهٔ سورس false است؛ CLIها فقط نشانگر عمومی بدون پیوند را می‌خوانند و پیش از دسترسی به تنظیمات، شبکه یا دارایی عملیات را رد می‌کنند. نشانگر آمادهٔ مصنوعی دادهٔ آزمون است و آمادگی برنامهٔ تحویل‌شده نیست. [تحویل](deployment.fa.md)، [عملیات](release-operations.fa.md) و [بازبینی امنیت](security/authentication-review.fa.md) قرارداد محلی فعلی را از پذیرش runtime آینده جدا می‌کنند.

[پایهٔ اجراکننده‌ها](runner-foundation.fa.md) شش ماژول Node و شش فایل آزمون مالک با پوشش واقعی برای ورودی صریح، چرخهٔ عمر فرزند مستقیم، راه‌اندازی fixture مستقل و API و خروجی محدود تحلیل اضافه می‌کند. عملیات ورودی وب‌سایت، API، سرور و تحلیلگر ابتدا نشانگر عمومی آمادگی را می‌خواند و مجموعهٔ فعلی با applicationReady:false را رد می‌کند. import فایل، dotenv نمی‌خواند، محیط را تغییر نمی‌دهد و سرویسی آغاز نمی‌کند. آزمون‌ها برنامه‌های مصنوعی Node متعلق به خود، شامل خطا و لغو، را اجرا می‌کنند؛ ساخت یا اجرای واقعی Next.js، API مستقل، مرورگر، موتور Docker یا تحلیل آزمایشگاهی اجرا نمی‌شود. دروازهٔ یازده‌بررسی بدون کاهش حد پوشش یا استثنای سورس، ابزار جدید را اندازه می‌گیرد. [پایهٔ مرورگر](browser-foundation.fa.md) اکنون مجموعهٔ آزمون نوشته‌شده با بررسی نوع، پیکربندی Playwright با آمادگی پیش از عملیات و اجرای کنترل‌شدهٔ visual/CSP را اضافه می‌کند. چهار فایل آزمون Node محافظ‌ها و رفتار تزریق‌شده را اندازه می‌گیرند؛ فایل اجرایی مرورگر، API مستقل و اجرای واقعی مرورگر یا مقایسهٔ تصویر همچنان به آینده موکول‌اند.
