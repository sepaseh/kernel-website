# بازبینی فهم سورس وب‌سایت — ۲۴ اکتبر ۲۰۲۶

[English](source-comprehension-2026-10-24.md) · [فارسی](source-comprehension-2026-10-24.fa.md)

هشت مورد وب‌سایت با سورس و معیار موجود بررسی شد: شش پوشش کامل و دو جزئی. کشف دستور دستی بود و بارگذاری خودکار میزبان سنجیده نشد. آزمودنی اجرای آزمون/برنامه/شبکه/نصب/ویرایش را گزارش نکرد و trace کامل او مستقلاً ابزارگذاری نشد. مدل/نسخه و زمان/توکن/هزینهٔ دقیق نامعلوم بود. این مشاهده بررسی runtime یا نرخ دقت عمومی مدل نیست.

| مورد                | نتیجه     | مشاهدهٔ ثبت‌شده                                                                                                                  |
| ------------------- | --------- | -------------------------------------------------------------------------------------------------------------------------------- |
| چرخهٔ نشست          | پوشش کامل | کوکی/حذف credential، مالکیت ابطال API و محافظ snapshot mutation درست بود.                                                        |
| مرجع زبان سایت      | پوشش کامل | تنظیم زنده، ده زبان، نبود مذاکرهٔ بازدیدکننده و خطای صریح درست بود.                                                              |
| معنای مشترک محلی    | پوشش کامل | reuse/common، ده زبان و مالکیت محلی پیام درست بود.                                                                               |
| مرز مبدأ proxy      | پوشش کامل | allowlist/مبدأ/اندازهٔ بدنه و no-store/حذف ترجیح زبان بازدیدکننده درست بود.                                                      |
| انتشار SEO          | پوشش کامل | ایندکس صریح production/HTTPS و کشف خانهٔ واقعی/noindex خصوصی درست بود.                                                           |
| کارایی و حریم خصوصی | پوشش جزئی | پیام محدود، SSR/motion/فونت، معیار استاندارد و نبود transport پوشش داده شد؛ منبع/مجوز/درست‌نویسی و مرز کش در این پاسخ کامل نبود. |
| انتشار nonce/CSP    | پوشش جزئی | nonce تازه/حذف هدر ورودی/حالت runtime درست بود؛ بی‌نیازی از rebuild و حفظ سیاست سایت در gateway صریح نبود.                       |
| انتشار تغییرناپذیر  | پوشش کامل | بستهٔ مستقل تغییرناپذیر، حذف داده/اسرار، guard لینک، cache هر انتشار و بازگشت مالک‌محور درست بود.                                |

پرسش منبع/مجوز/درست‌نویسی قلم و CSP زمان اجرا/درگاه بعداً روشن‌تر شد ولی همان پاسخ دوباره امتیاز نگرفت. پوشش جزئی شمار نقص runtime یا شاهد بهبود سنجیده‌شده نیست. [روش](../comprehension-evaluation.fa.md) و [ارزیابی نیازمندی](requirements-audit-2026-10-24.fa.md) را ببینید.
