## artifact واقعی استقرار محلی

بسته‌بند native، build واقعی standalone آماده‌شده را مصرف کرد. خروجی کامل به پوشهٔ موقت بیرون checkout منتقل و با وابستگی runtime همراه مستقیماً اجرا شد. API جدا با پایگاه/بارگذاری موقت ساختگی، مبدأ صریح و پورت loopback تصادفی اجرا شد. readiness، HTML خام، nonce CSP، noindex، تمام نشانی‌های JS/CSS/قلم استخراج‌شده، حذف credential از پاسخ ورود، انتقال کوکی HttpOnly، پاسخ حساب احرازشده و هدر private no-store موفق شدند. هر دو فرایند مستقیم و release/دادهٔ موقت حذف شدند. این اجرای payload در Windows x64 بود و آزمون systemd روی Linux نیست.

smoke Docker، وب‌سایت و درگاه TLS را از همین مخزن و API را از checkout مستقل ساخت. فقط entrypoint/config محیط آزمایشی API تغییر داده شد؛ Compose عادی وب‌سایت سرویس API ندارد. پروژهٔ Compose و volume یکتا، گواهی self-signed ساختگی و پورت loopback اجرا را جدا کردند. هدایت HTTP→HTTPS، دارایی و قلم standalone، بازسازی runtime از report-only به enforce، noindex، ورود/حساب واقعی با کوکی Secure/HttpOnly، private no-store و marker نسخه موفق شدند. container، volume، شبکه، فایل موقت و سه image با برچسب یکتا پاک شدند؛ image پایه و cache ساخت ماند و پاک‌سازی گسترده انجام نشد.

## شاهد و محدودیت

شاهد تولیدشدهٔ محلی در Git نادیده گرفته می‌شود: test-results/completion/full.log، test-results/completion/docker.log، test-results/deployment/native.json و test-results/deployment/docker.json. گزارش عادی مرورگر/تصویر نیز خروجی محلی است.

دادهٔ اپراتور، dotenv واقعی، حساب زنده، سرویس production یا گواهی واقعی استفاده نشد. commit، push یا اجرای workflow راه‌دور انجام نشد. نصب Linux systemd/ACME، اجرای CI/CodeQL/Sonar/ZAP میزبانی‌شده، حفاظت شاخه، ارائه‌دهندهٔ OTP در production، انتشار عمومی، معیار Lighthouse/کاربر واقعی و انطباق کامل WCAG خارج از این بررسی محلی‌اند. آزمون API خصوصی در CI به token فقط‌خواندنی و revision غیرقابل‌تغییر API تحت مدیریت اپراتور نیاز دارد؛ اینجا رمزی ساخته یا خوانده نشد.
