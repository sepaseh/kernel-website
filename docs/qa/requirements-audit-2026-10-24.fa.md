# ممیزی نیازمندی‌های وب‌سایت — ۲۴ اکتبر ۲۰۲۶

[English](requirements-audit-2026-10-24.md) · [فارسی](requirements-audit-2026-10-24.fa.md)

یادداشت انتشار: مسیرهای سورس اولیه در این گزارش به‌صورت ارجاع بایگانی‌شده نگه داشته شده‌اند؛ یکپارچه‌سازی اجرایی آن‌ها ممکن است هنوز منتشر نشده باشد. معیار پذیرش فعلی در [راهنمای برنامه](../application.fa.md) است. تاریخ و یافته‌های این گزارش تغییر نکرده‌اند.

این ارزیابی تاریخ‌دار نیازمندی و موضوع برنامه‌ریزی وب‌سایت را بررسی می‌کند. هر موضوع دستور نصب همهٔ فناوری‌ها نیست؛ پیاده‌شده یعنی سورس مالک وجود دارد، پیکربندی‌شده یعنی ابزار/گردش‌کار قابل‌اجرا وجود دارد و تأییدشده فقط اجرای مشخص ثبت‌شده را توصیف می‌کند.

## اصلاح‌های انجام‌شده

رگرسیون پروفایل دیرهنگام ابتدا روی خروجی production قبلی ناموفق شد: حساب B
بارگذاری شده بود، سپس پاسخ دیرهنگام حساب A کلید snapshot در provider را جایگزین
کرد و حساب در بارگذاری ماند. guard تابعی کلید snapshot، بدون پکیج تازه، تغییر
معنای HTTP/نشست یا بازنویسی API آن را رفع کرد. نقشهٔ مسیر و شاهد ارزیابی اکنون
provider و رگرسیون را هم دارند تا کار آینده مرز نسل نشست کلاینت را دنبال کند.

راهنمای دسترس‌پذیری فقط مسیر و فرمان متعلق به وب‌سایت را پوشش می‌دهد. تصویر شاهد در test-results/website/evidence نادیده‌گرفته‌شده و داخل artifact CI ثبت می‌شود. نتیجهٔ کارایی و استقرار تاریخ و محدودهٔ ثبت‌شدهٔ خود را حفظ می‌کند.

## اجرای تازه و محدودیت‌ها

پیش از ویرایش فریم‌ورک، راهنمای server/client و use-client نصب‌شدهٔ Next 16.4.2
خوانده شد. Node 24.18.0 و پیکربندی fixture مصنوعی به کار رفت.

- رفتار قبلی بازتولید شد: آزمون متمرکز تازه پس از آزادشدن پاسخ قدیمی در بررسی
  نهایی دیده‌شدن حساب ناموفق شد.
- ساخت production تازه و حالت متمرکز اصلاح‌شده موفق شدند؛ سپس هر ۴۸ سناریوی
  مرورگر روی همان ساخت، شامل هر ده زبان/SEO، ورود و حساب، اعمال nonce،
  دسترس‌پذیری و رقابت تازه، موفق بودند.
- npm run test:unit موفق بود: ۱۷۱ تست وب‌سایت، ۹ تست کاتالوگ و ۳۹ تست ابزار.
  این تعدادهای هر دستور، جمعِ سناریوهای منحصربه‌فرد برنامه نیستند.
- typecheck، lint، Knip، مرز import و ۱۴ رگرسیون راهنما موفق بودند. بودجهٔ تازه
  با JavaScript مرورگر ۸۲۴٬۱۱۷ بایت، بزرگ‌ترین فایل ۲۳۵٬۰۴۴ و CSS برابر ۳۷٬۴۵۲
  پاس شد؛ هیچ سقفی بازتر نشد.
- پس از تغییر مسیر خروجی، دو سناریوی متمرکز مرورگر واقعی موفق شدند و هر هشت PNG
  شاهد داخل test-results/website/evidence که ignored است ساخته شد. قالب‌بندی و
  راهنمای نهایی محلی موفق بودند؛ ادعای پروفایل کامل تازه یا CI راه‌دور وجود ندارد.

در این ممیزی تصویر Docker برنامه دوباره ساخته نشد، dotenv/وضعیت واقعی خوانده
نشد و درخواست production، commit یا push انجام نشد. شاهد تقسیم، بستهٔ native،
Docker و تصویر قبلی در [گزارش پیشین](independent-website-verification.fa.md)
مانده است و این ممیزی آن را اجرای تازه نمی‌نامد. Lighthouse تازه، INP/p75 کاربران
واقعی، ارزیابی دستی صفحه‌خوان یا benchmark درک AI بدون آلودگی زمینه اجرا نشد.

## انتخاب‌ها و پیشنهادهای باقی

برای محصول مستقر، پیش از بازکردن ثبت‌نام، بازیابی و تأیید ایمیل، ارسال OTP متعلق
به API را پیکربندی و بررسی کنید. دامنهٔ عمومی، نمایه‌سازی، تمدید گواهی، مالکیت
backup/recovery و اعتبارنامهٔ CI خصوصی را برای محیط واقعی انتخاب کنید. این‌ها
تصمیم اپراتور/provider هستند و فریم‌ورک تازهٔ وب‌سایت نمی‌خواهند.

پیش از ادعای انطباق، ارزیابی کوتاه دستی دسترس‌پذیری را ثبت کنید. اگر سایت واقعی
RUM لازم داشت، رضایت، sampling، نگهداری و انتقال را آگاهانه روی آداپتر موجود
طراحی کنید؛ collector خودکار ناخواسته روشن نشود. SSG/ISR، ابطال cache محتوا،
CMS/رسانه/ویدئو، OAuth، offline/PWA، realtime و قابلیت AI محصول همچنان مشروط‌اند.
آزمایش Serena/Graphify/Repomix/Context7 باید مسئلهٔ اندازه‌گیری‌شدهٔ کشف راهنما یا
درک کد داشته باشد؛ هیچ‌یک وابستگی مفقود runtime نیست. [تحویل نیازمندی و برنامهٔ پیاده‌سازی](../change-workflow.fa.md)
و [سیاست مالکیت تست ناپایدار](../test-reliability.fa.md)، F038 و F081/F082 را به
شکل سند workflow محلی پیاده می‌کنند؛ runtime یا تشخیص خودکار تست ناپایدار اضافه
نمی‌کنند.

پس از این ممیزی حوزه‌ای، [ارزیابی جداگانهٔ توضیح منبع](source-comprehension-2026-10-24.fa.md) اجرا شد؛ کشف دستی و پوشش جزئی معیارها به معنی بنچمارک همهٔ دستیارها یا اجرای دوبارهٔ تست‌ها نیست.

[جدول کامل ۱۳۷ موضوع](roadmap-status-2026-10-24.fa.md) وضعیت هر سه مالک را کنار هم نشان می‌دهد؛ [تحویل/برنامهٔ کار](../change-workflow.fa.md) و [رسیدگی به تست ناپایدار](../test-reliability.fa.md) گردش‌کار محلی هستند و سرویس اجرایی اضافه نمی‌کنند.
