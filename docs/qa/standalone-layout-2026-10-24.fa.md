# اعتبارسنجی وب‌سایت — ۲۴ اکتبر ۲۰۲۶

[English](standalone-layout-2026-10-24.md) · [فارسی](standalone-layout-2026-10-24.fa.md)

این گزارش تاریخ‌دار نسخهٔ بررسی‌شدهٔ وب‌سایت و نتیجه/محدودیت واقعی آن را ثبت می‌کند؛ به معنی اجرای کامل تازه یا موجودی فعلی Docker نیست.

## بررسی اجراشده

هر ۱۵ دروازهٔ الزامی پس از نصب تمیز ریشه گذشت: ۱۵ تست راهنما، مرزهای ۹۷ ماژول تولید، ممیزی وابستگی با صفر یافته، typecheck، lint بدون هشدار، قالب‌بندی، ۱۷۱ تست واحد، نه تست کاتالوگ، ۳۹ تست tooling، ۲۴ تست استقرار/راه‌اندازی، Knip و ساخت Next.js. بودجه‌های قبلی با ۸۲۴٬۱۱۸ بایت JavaScript، بزرگ‌ترین قطعهٔ ۲۳۵٬۰۴۴ بایتی و ۳۹٬۶۲۴ بایت CSS گذشتند. هر ۴۸ سناریوی مرورگر واقعی، چهار case از CSP در حالت report-only و چهار مقایسهٔ تصویری ثابت بدون به‌روزرسانی یا تأیید تازهٔ baseline گذشتند.

بستهٔ native تازه‌ساخته‌شده خارج از checkout جابه‌جا شد و هفت بررسی واقعی را گذراند: SSR، noindex، JavaScript، تحویل قلم، حذف فیلدهای اعتبارنامه، کوکی نشست HttpOnly و دسترسی حساب از API مستقل. ورودی آن `website/server.js` است؛ فرایند، بسته و fixture موقت پاک شدند.

شاهد شکست اولین اجرای مرورگر حفظ شد؛ آن اجرا دو import محاسبه‌شدهٔ مختص تست را نشان داد که بارگذار آن‌ها resolve نمی‌شد. این تست‌ها اکنون از نقشهٔ صریح بارگذاری زبان تولید استفاده می‌کنند و هر ۴۸ سناریو دوباره موفق شدند. سیاست retry، skip یا آستانهٔ assertion تضعیف نشده است.

smoke واقعی داکر به Dockerfile ریشه رسید، ولی Docker Hub/CloudFront برای فرادادهٔ image ثابت Node پیش از ساخت سورس برنامه خطای HTTP 403 داد. اجرای موفق image لینوکسی ادعا نمی‌شود. directive اختیاری frontend خارجی Dockerfile حذف شد و دستورهای استاندارد از frontend همراه BuildKit استفاده می‌کنند. پس از این تغییر هر ۲۴ تست بسته‌بندی، راه‌اندازی و استقرار دوباره گذشت.

نبود هر پنج builder موقت این تلاش‌ها تأیید شد. کانتینر، شبکهٔ اختصاصی، volume، image برنامه، کش builder و fixture داکر تست‌ها حذف شدند؛ image تازه‌دریافت‌شدهٔ ابزار مشترک BuildKit نیز پس از مجموعهٔ تست حذف شد. موجودی نهایی داکر صفر image، کانتینر، volume و بایت کش ساخت بود. global prune به کار نرفت.

## حدود شواهد

قطع اجباری درخت فرایند Windows پنج fixture ساختگی مرورگر با مجموع ۷۹۸٬۷۲۰ بایت SQLite آزمایشی و پوشهٔ upload خالی باقی گذاشت؛ listener فعالی وجود نداشت. پاک‌سازی آن‌ها تکمیل نشد. این محدودیت با پاک‌سازی موفق بستهٔ native و منابع Docker جداست.

تست محلی به معنی اجرای CI میزبانی‌شده، انتشار تولید، فعال‌سازی systemd در Linux، تأیید دستی screen reader یا تکمیل یکپارچه‌سازی محصول وابسته به provider نیست. سیاست پاک‌سازی داکر همچنان حذف دقیق منابع همان تست پس از هر اجرا، از جمله شکست، است؛ global prune به کار نمی‌رود.
