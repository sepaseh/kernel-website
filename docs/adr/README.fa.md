# تصمیم‌های معماری

[English](README.md) · [فارسی](README.fa.md)

این تصمیم‌های پذیرفته‌شده، مالکیت سورس و سرویس و مرز هدف runtime، HTTP، زبان و
نشست وب‌سایت را تعریف می‌کنند. یادداشت پیاده‌سازی، پشتیبانی محلی منتشرشده را از
یکپارچه‌سازی قابل اجرای آینده جدا می‌کند. پذیرش تصمیم، شاهد اجرای build، مسیر
مرورگر یا استقرار نیست. پیش از تغییر مرز، سورس مالک و آزمون را بخوانید.
