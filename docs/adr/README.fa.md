# تصمیم‌های معماری

[English](README.md) · [فارسی](README.fa.md)

این تصمیم‌های پذیرفته‌شده، مالکیت سورس و سرویس و مرز هدف runtime، HTTP، زبان و
نشست وب‌سایت را تعریف می‌کنند. وضعیت تحویل از
[نشانگر انتشار](../../.github/bootstrap-policy.json)، موجودی دقیق و
[پذیرش برنامه](../application.fa.md) مشخص می‌شود، نه وضعیت ADR. یادداشت
پیاده‌سازی، شاهد پشتیبان با نشانگر false را از شاهد اجرای برنامه و استقرار جدا
می‌کند. پذیرش تصمیم، شاهد اجرای build، مسیر
مرورگر یا استقرار نیست. پیش از تغییر مرز، سورس مالک و آزمون را بخوانید.
