# تصمیم ۰۰۰۵: مالکیت محلی سورس

[English](0005-independent-repositories.md) · [فارسی](0005-independent-repositories.fa.md)

وضعیت: پذیرفته‌شده.

سورس متعلق به همین پروژه است. رفتار قابلیت و DTO درخواست اختصاصی کنار قابلیت،
قرارداد تنظیمات کنار بارگذار و مفهوم HTTP واقعاً چندمصرفی در src/shared/contracts
قرار دارد. UI و hook مشترک و زیرساخت سراسری HTTP، قلم، امنیت، SEO، زبان و کارایی
مالک معنایی خود را نگه می‌دارند؛ یک فراخوانندهٔ bootstrap زیرساخت را اختصاصی
قابلیت نمی‌کند.

هر زبان یک کاتالوگ کامل TypeScript با نام کد زبان دارد. معنای مشترک یک کلید سادهٔ
ریشه دارد؛ کلید اختصاصی حساب و ورود با پیشوند صریح در همان شیء تخت قرار می‌گیرد.
تغییر کاتالوگ محلی است. مسیر، DTO، کوکی و تنظیمات همچنان به سازگاری HTTP با API
مستقل هنگام انتشار نیاز دارند.

Reveal و آزمونش زیر website/home هستند. Preferences هنگام ترکیب در پوستهٔ برنامه
مالکیت معنایی مشترک را حفظ می‌کند. ترکیب Header و Footer باید در موجودی دقیق
برنامه باشد و طبق [قرارداد برنامه](../application.fa.md) پوشش بگیرد؛ پیش‌نیاز با
نشانگر false شاهد آن اتصال نیست. وابستگی
سورس runtime به checkout دیگر یا بستهٔ سورس محلی نصب‌شده مجاز نیست. پروژه باید
یک بستهٔ مستقل قابل نصب در ریشه بماند.

[ترجمه](../localization.fa.md) و [بررسی مرجع](../../.agents/validation.json) را بخوانید.
