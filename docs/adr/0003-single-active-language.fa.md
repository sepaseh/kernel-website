# تصمیم ۰۰۰۳: یک زبان فعال

[English](0003-single-active-language.md) · [فارسی](0003-single-active-language.fa.md)

وضعیت: پذیرفته‌شده؛ بارگذاری زبان و کاتالوگ محلی منتشر است.

فقط تنظیم ذخیره‌شدهٔ API عمومی، کد زبان پشتیبانی‌شده و جهت معتبر ltr/rtl را
انتخاب می‌کند. registry محلی کد را اعتبارسنجی می‌کند و جهت را محاسبه نمی‌کند.
بارگذار بدون کوکی یا header ترجیح زبان بازدیدکننده، no-store استفاده می‌کند.
تنظیم ناموجود، خراب یا پشتیبانی‌نشده خطای صریح دارد و پنهانی به انگلیسی
برنمی‌گردد. فرادادهٔ تقویم و نام نمایشی اینجا تکرار نمی‌شود.

هر یک از ده کاتالوگ با نام کد زبان، یک نگاشت کامل تخت با مقدار رشته در ریشه
است. کلید مشترک ساده، پیشوند صریح قابلیت، ترجمهٔ واقعی و متغیر ICU همسان را
حفظ کنید. provider و اجرای ترجمه بیرون دادهٔ خالص می‌مانند؛ کلاینت گروه صریح
root/auth/account را انتخاب می‌کند.

طراحی پذیرفته‌شدهٔ URL، مسیر canonical بدون پیشوند و بدون انتخاب زبان
بازدیدکننده، cookie یا مذاکرهٔ مرورگر است. پذیرش برنامه باید مسیر، lang/dir
سند، metadata و redirect پیشوند قدیمی را روی درخت دقیق runtime بسنجد. آزمون
پشتیبان با نشانگر false این رفتارها را ثابت نمی‌کند.
[قرارداد برنامه](../application.fa.md) را بدون تغییر مرجع زبان API اجرا کنید.

[registry](../../src/i18n/catalog-data/locales.ts)،
[بارگذار زبان](../../src/shared/settings/language.ts)،
[ترجمه](../localization.fa.md) و
[آزمون یکپارچگی کاتالوگ](../../src/i18n/catalog-data/integrity.test.ts) را بخوانید.
محصول با زبان انتخابی بازدیدکننده به تصمیم تازه دربارهٔ URL، cache و metadata
نیاز دارد.
