# تصمیم ۰۰۰۴: نشست کوکی

[English](0004-cookie-proxy-and-sessions.md) · [فارسی](0004-cookie-proxy-and-sessions.fa.md)

وضعیت: پذیرفته‌شده؛ انتقال محلی، نشست و مالکیت فرم منتشر است.

از کوکی نشست HttpOnly در مرز هم‌مبدأ با فهرست محدود ورود و حساب استفاده کنید.
پشتیبانی پراکسی Set-Cookie بومی و وضعیت و خطای API را حفظ، Origin خارجی نوشتن
را رد، فیلد اعتبارنامهٔ پاسخ موفق ورود را از JSON حذف و پاسخ را private/no-store
می‌کند. JavaScript وب‌سایت bearer ذخیره نمی‌کند.
[قرارداد برنامه](../application.fa.md) شاهد واقعی مسیر متصل و جداسازی کوکی مرورگر
را لازم دارد؛ آزمون helper با نشانگر false آن را ثابت نمی‌کند.

نگه‌داری رمز، مجوز، نشست ذخیره‌شده و معنای ابطال پس از تغییر یا بازیابی رمز با
API مستقل است. ارسال واقعی OTP به فراهم‌سازی API و اپراتور نیاز دارد. این تصمیم
مالکیت، پیاده‌سازی سرویس، چرخش JWT یا تشخیص استفادهٔ مجدد را ثابت نمی‌کند.

SessionProvider خواندن و ویرایش پذیرفته‌شده را به زبان و نسل بارگذاری‌شده محدود
می‌کند. refresh فوراً snapshot قبلی را بی‌اعتبار می‌کند. فرم قابلیت با زبان،
نسل و هویت حساب بازنشانی می‌شود و guard عملیات mount، بازخورد و هدایت منقضی را
کنار می‌گذارد. پاسخ 401 ورود عمومی بازخورد فرم خودش را نگه می‌دارد؛ اعلان 401
نوشتن محافظت‌شده همچنان نشست را تازه می‌کند. guard نمی‌تواند نوشتن تکمیل‌شدهٔ
سرور را برگرداند.
