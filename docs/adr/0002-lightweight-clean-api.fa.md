# تصمیم ۰۰۰۲: مرز HTTP

[English](0002-lightweight-clean-api.md) · [فارسی](0002-lightweight-clean-api.fa.md)

وضعیت: پذیرفته‌شده؛ پشتیبانی محلی HTTP و پراکسی منتشر است.

وب‌سایت HTTP مصرف می‌کند و SDK بک‌اند، تنظیم ورود، پیاده‌سازی ماندگاری یا
ذخیره‌سازی را وارد نمی‌کند. DTO درخواست اختصاصی کنار قابلیت، قرارداد تنظیمات
کنار بارگذار و مفهوم HTTP چندمصرفی در src/shared/contracts است. ماژول قرارداد
مستقل از framework می‌ماند.

کلاینت مرورگر مسیر هم‌مبدأ /api را هدف می‌گیرد. پشتیبانی پراکسی منتشرشده فهرست
مسیر و روش مجاز، Origin نوشتن، محدودیت بدنه، انتقال کوکی، حذف اعتبارنامه و پاسخ
خصوصی no-store را مالک است. مسیر برنامه باید همین مرز را متصل و درخواست واقعی
را بررسی کند؛ پیش‌نیاز با نشانگر false فقط helper را می‌سنجد.
[قرارداد برنامه](../application.fa.md) این شاهد را از پذیرش درگاه و استقرار جدا
می‌کند. اعتبارسنجی، مجوز و نوشتن اتمی با API است؛ فرم و
guard جایگزین آن نیستند.

[پشتیبانی پراکسی](../../src/shared/api/proxy.ts)،
[آزمون آن](../../src/shared/api/proxy.test.ts)،
[import](../../.agents/rules/imports.md)، [فرم‌ها](../forms.fa.md) و
[مرز سرور](../server-boundary.fa.md) را بخوانید. تغییر ناسازگار مسیر، DTO یا
کوکی را پیش از انتشار مصرف‌کننده هماهنگ کنید. آزمون ساختگی محلی رفتار استقرار
واقعی API را ثابت نمی‌کند.
