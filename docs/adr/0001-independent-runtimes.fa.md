# تصمیم ۰۰۰۱: اجرای وب‌سایت

[English](0001-independent-runtimes.md) · [فارسی](0001-independent-runtimes.fa.md)

وضعیت: معماری پذیرفته‌شده؛ وضعیت تحویل از نشانگر انتشار مشخص می‌شود.

یک بستهٔ مستقل در ریشه با سورس src/، دارایی public/ و manifest و lockfile متعلق
به خود داشته باشید. runtime هدف Next App Router است. API مستقل از HTTP مصرف
می‌شود و ورود، اعتبارنامه، migration پایگاه، ماندگاری و ذخیره‌سازی را مالک است.

پیش‌نیاز با نشانگر false پشتیبان، فرم و ابزار آزمون محافظت‌شده را منتشر می‌کند
و اجرای صفحه، layout ریشه، آداپتر درخواست یا CSS را ثابت نمی‌کند. اتصال برنامه
باید محتوای
عمومی و زبان و جهت API را در Server Component رندر، تعامل مرورگر را به مرز
کلاینت محدود و cache مشترک پاسخ خصوصی و تنظیمات را ممنوع کند. بستهٔ تولید
standalone و مبدأ صریح API سرور الزام تحویل‌اند. [قرارداد برنامه](../application.fa.md)
پذیرش درخت دقیق را تعریف می‌کند؛ پذیرش تصمیم شاهد اجرای build نیست.

[معماری](../architecture.fa.md)، [راهنمای مرحله](../bootstrap.fa.md)،
[بستهٔ پروژه](../../package.json) و [بررسی مرجع](../../.agents/validation.json)
را بخوانید. نوع محلی یا آزمون پشتیبان به‌تنهایی سازگاری API منتشرشده، SSR، رفتار
مرورگر یا استقرار را ثابت نمی‌کند.
