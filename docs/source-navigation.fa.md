# ناوبری وظایف وب‌سایت

[English](source-navigation.md) · [فارسی](source-navigation.fa.md)

از [دستور ریشه](../AGENTS.md)، [تنظیمات](../.agents/settings.json) و وظیفهٔ مرتبط در
[ناوبری](../.agents/navigation.json) شروع کنید. نقشهٔ ماشینی مالک مسیرهای محلی سورس،
قرارداد، آزمون، قاعده و شناسهٔ بررسی است. تابع مالک را کامل بخوانید؛ فهرست مسیر،
کامل‌بودن معنایی یا بارگذاری خودکار دستور را ثابت نمی‌کند.

نقشه محدودهٔ پشتیبان و قابلیتِ منتشرشده و غیرقابل‌اجرا را پوشش می‌دهد. نباید به
مسیر، layout و CSS یا استقرار آینده به عنوان فایل موجود اشاره کند؛ آزمون نوشته‌شدهٔ مرورگر نیز نباید به عنوان مسیر مرورگری اجراشده معرفی شود.
[معماری](architecture.fa.md) و [تصمیم‌ها](adr/README.fa.md) طراحی پذیرفته‌شده را
از یکپارچه‌سازی تحویل‌شده جدا می‌کنند.

- برای فرم و رقابت نشست، مالک قابلیت، ماژول و نوع HTTP و رفتار
  [فرم](forms.fa.md) و [نشست](session.fa.md) را بخوانید. لغو، تعویض نسل، بازخورد،
  مقصد OTP و هدایت قدیمی را دنبال کنید.
- برای مالکیت HTTP، types.ts قابلیت، قرارداد تنظیمات و ماژول مشترک را بررسی کنید.
  ورود واقعی، داده و ذخیره‌سازی با API مستقل است.
- برای زبان و پیام، بارگذار زبان API، یک شیء locales/code.ts برای هر زبان، نوع
  کلید مشتق از انگلیسی، loader صریح و گروه root/auth/account کلاینت را بخوانید.
  جهت API از کد زبان محاسبه نمی‌شود.
- برای طراحی، از [DESIGN](../DESIGN.fa.md)،
  [skill طراحی](../.agents/skills/design-ui/SKILL.md) و اجزای محلی شروع کنید.
  کلاس معنایی، CSS محاسبه‌شده، تصویر یا شاهد مرورگر نیست.
- برای پشتیبانی HTTP، CSP، SEO، قلم و کارایی، سورس مالک و آزمون مستقیمش را باز کنید.
  این توابع، یکپارچگی مسیر یا سند زنده را ثابت نمی‌کنند.
- برای Git و بازبینی، از وظیفهٔ git-workflow، [راهنمای Git](../.agents/rules/git.md)،
  [شاخه](../.agents/rules/branches.md)، [commit](../.agents/skills/commit/SKILL.md)
  و [شروع issue](../.agents/skills/start-issue/SKILL.md) استفاده کنید. کار موجود را
  حفظ و base واقعی را بررسی کنید؛ آماده‌سازی، فرادادهٔ بیرونی منتشر نمی‌کند.

بررسی را از [manifest مرجع](../.agents/validation.json) و
[سیاست مشارکت](../CONTRIBUTING.fa.md) انتخاب کنید. تازگی سورس، اجرای واقعی، شکست،
skip و محدودیت را ثبت کنید. خط جست‌وجوی مطابق یا موفقیت گذشته، بررسی تازه نیست.
[ارزیابی](comprehension-evaluation.fa.md) ناوبری ایستا، کشف مشاهده‌شدهٔ دستور و
درک سنجیده‌شدهٔ سورس را جدا بررسی می‌کند.

برای ابزار مستقل کیفیت، از وظیفهٔ integration-tooling در ناوبری ماشینی و [آزمون](testing.fa.md) شروع کنید. تعیین‌کنندهٔ صریح مسیر API، تجزیه‌گر بسته و بودجه، محیط کارایی و ابزار فراداده و قفل بصری و سه فایل آزمون مالک آن‌ها در Node را بخوانید. بررسی الزامی آن‌ها پوشش اندازه‌گیری‌شدهٔ گردش‌کار است؛ مسیر مرورگر، اجراکننده‌ها و سازگاری تصاویر تاریخی خارج از این مرحله باقی می‌مانند.

برای ابزارهای تحویل، مالک منتشرشدهٔ آمادگی، کپی و بسته، تنظیم عمومی، سلامت با مقصد صریح، پاک‌سازی محدود و اعتبارسنجی مقصد را از وظیفهٔ delivery-tooling در ناوبری ماشینی بخوانید. [آماده‌سازی استقرار](deployment.fa.md) و [عملیات انتشار](release-operations.fa.md) شاهد مصنوعی و قالب غیرفعال را شرح می‌دهند. بررسی الزامی، پوشش اندازه‌گیری‌شدهٔ گردش‌کار است؛ CLIهای اصلی تحویل در مرحلهٔ `applicationReady:false` عملیات را پیش از خواندن تنظیمات، شبکه یا دسترسی به artifact رد می‌کنند. گردش‌کارهای راه‌دور همچنان موکول‌اند.

[پایهٔ اجراکننده‌ها](runner-foundation.fa.md) شش ماژول Node و شش فایل آزمون مالک با پوشش واقعی برای ورودی صریح، چرخهٔ عمر فرزند مستقیم، راه‌اندازی fixture مستقل و API و خروجی محدود تحلیل اضافه می‌کند. عملیات ورودی وب‌سایت، API، سرور و تحلیلگر ابتدا نشانگر عمومی آمادگی را می‌خواند و مجموعهٔ فعلی با applicationReady:false را رد می‌کند. import فایل، dotenv نمی‌خواند، محیط را تغییر نمی‌دهد و سرویسی آغاز نمی‌کند. آزمون‌ها برنامه‌های مصنوعی Node متعلق به خود، شامل خطا و لغو، را اجرا می‌کنند؛ ساخت یا اجرای واقعی Next.js، API مستقل، مرورگر، موتور Docker یا تحلیل آزمایشگاهی اجرا نمی‌شود. دروازهٔ یازده‌بررسی بدون کاهش حد پوشش یا استثنای سورس، ابزار جدید را اندازه می‌گیرد. [پایهٔ مرورگر](browser-foundation.fa.md) اکنون مجموعهٔ آزمون نوشته‌شده با بررسی نوع، پیکربندی Playwright با آمادگی پیش از عملیات و اجرای کنترل‌شدهٔ visual/CSP را اضافه می‌کند. چهار فایل آزمون Node محافظ‌ها و رفتار تزریق‌شده را اندازه می‌گیرند؛ فایل اجرایی مرورگر، API مستقل و اجرای واقعی مرورگر یا مقایسهٔ تصویر همچنان به آینده موکول‌اند.
