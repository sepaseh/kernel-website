# درک سورس

[English](ai-code-understanding.md) · [فارسی](ai-code-understanding.fa.md)

از جست‌وجوی محلی، [AGENTS](../AGENTS.md) و مالک، قرارداد، قاعده و آزمون وظیفه در
[ناوبری](../.agents/navigation.json) شروع کنید. تابع مالک را کامل بخوانید و ورودی،
خطا، سازگاری HTTP، نشست، حریم خصوصی cache، زبان و تازگی سورس را دنبال کنید.
دستیار و index اختیاری وابستگی runtime نیستند.

[راهنمای ارزیابی](comprehension-evaluation.fa.md) بررسی مسیر و دستور، کشف
مشاهده‌شدهٔ دستور و کیفیت پاسخ را جدا می‌کند. ابزار پیشنهادی، اندازه‌گیری اجراشده
و موارد نامعلوم را تفکیک کنید. index یا بارگذاری بیرونی به هدف واقعی، محدودهٔ
صریح داده و مجوز اقدام بیرونی نیاز دارد. کار عادی سورس به سرویس خاصی وابسته نیست.

ناوبری این مرحله فقط مالک پشتیبان، قابلیت و راهنمای منتشرشده را دارد. طراحی
runtime پذیرفته‌شدهٔ آینده، سورس قابل اجرای فعلی نیست. پیش از پاسخ snapshot دقیق
را بررسی کنید و نبود شاهد build، مرورگر یا استقرار را صریح بنویسید.
