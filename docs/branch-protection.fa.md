# حفاظت شاخه بر اساس مرحله

[English](branch-protection.md) · [فارسی](branch-protection.fa.md)

مرحلهٔ مصوب **پایه** با `applicationReady:false` و فهرست بستهٔ سورس همچنان
غیرقابل اجراست. مجموعهٔ بررسی‌های بومی الزامی آن عبارت است از:

| بررسی الزامی مرحلهٔ پایه   | App مورد انتظار در GitHub      |
| -------------------------- | ------------------------------ |
| `check`                    | GitHub Actions، شناسهٔ `15368` |
| `SonarQube Cloud analysis` | GitHub Actions، شناسهٔ `15368` |
| `SonarCloud Code Analysis` | SonarCloud، شناسهٔ `12526`     |
| `CodeRabbit`               | CodeRabbit، شناسهٔ `347564`    |

job واقعی پایه محدودهٔ منتشرشده را بررسی می‌کند؛ job اسکن و دروازهٔ کیفیت
سرویس دو الزام جدا هستند. jobهای برنامه با نام `build`، `e2e` و
`visual` خارج از سیاست پایه‌ای هستند که صریحاً تصویب شده است. job ساختگی،
بررسی اجرا‌نشده یا ادعای آمادگی برنامه جای آن‌ها را نمی‌گیرد.

سایر حفاظت‌ها را حفظ کنید: یک بازبینی تأییدشده، حل گفتگوها، ابطال تأیید قدیمی،
بررسی سخت‌گیرانهٔ به‌روز بودن شاخه، اعمال قانون برای مدیران، تاریخچهٔ خطی و
ممنوعیت force push و حذف شاخه. شمارش تأیید بومی به‌تنهایی تأیید را به یک ربات
مقید نمی‌کند. CODEOWNERS بازبین پیشنهاد می‌کند و حفاظت را تنظیم نمی‌کند.
تغییر سیاست دوردست به اجازهٔ صریح و تأیید نام واقعی بررسی‌ها و هویت Appها
نیاز دارد.

پیش از **ادغام هر برنامهٔ قابل اجرا**، jobهای واقعی build رابط، مرورگر و CSP
و تصاویر را اضافه و موفقیت آن‌ها را روی head پیشنهادی مشاهده کنید؛
**`build`، `e2e` و `visual` را الزامی کنید** و اعتبارسنجی کامل مرجع
را گسترش دهید. برای شواهد HTTP، احراز هویت و مرورگر از fixture مصنوعی API
استفاده کنید که مستقلاً منتشر شده باشد. اعتبارسنجی پایه آمادگی برنامهٔ قابل
اجرا را ثابت نمی‌کند.

درخواست دستی CodeRabbit همچنان به [تمام پیش‌شرط‌ها](sonarqube.fa.md#پیش-از-درخواست-بازبینی-coderabbit)
نیاز دارد: تمام بررسی‌های فعلاً الزامی غیر از CodeRabbit برای head تازه موفق
باشند و گزارش مرتبط Sonar هیچ یافتهٔ OPEN یا حل‌نشده در هیچ سطح شدت نداشته
باشد. مثبت کاذب مستندشدهٔ S9382 تا وقتی در سرویس OPEN است همچنان مانع است.
head تازه را دوباره بررسی، سهمیه را رعایت و درخواست در حال اجرا را تکرار
نکنید. تأیید خودکار فعال و تأیید با دستور نویسنده غیرفعال است. بازبینی
اجرا‌نشده، شاهد بازبینی واقعی نیست.
