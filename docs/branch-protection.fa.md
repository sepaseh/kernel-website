# حفاظت شاخه

[English](branch-protection.md) · [فارسی](branch-protection.fa.md)

از حفاظت بومی GitHub با یک بازبینی تأییدشده، حل گفتگوها، ابطال تأیید قدیمی،
شاخهٔ به‌روز و اعمال قانون برای مدیران استفاده کنید. force push و حذف شاخه
غیرفعال باشند. تغییر دوردست به اجازهٔ صریح نیاز دارد.

| بررسی بومی                        | App                     |
| --------------------------------- | ----------------------- |
| `check`، `build`، `e2e`، `visual` | GitHub Actions، `15368` |
| `CodeRabbit`                      | CodeRabbit، `347564`    |
| `SonarCloud Code Analysis`        | SonarCloud، `12526`     |

مرحلهٔ پایه job واقعی `check` و job جداگانهٔ **SonarQube Cloud analysis**
را دارد. jobهای برنامه با نام `build`، `e2e` و `visual` در این مرحله
وجود ندارند. الزامات موجود این jobها همچنان مسدودند؛ این تغییر سورس آن‌ها را
حذف نمی‌کند، موفقیت ساختگی نمی‌سازد و مجوز تغییر حفاظت نیست.

بازبینی خودکار، افزایشی و پیش‌نویس CodeRabbit خاموش است. برای هر PR مجاز
یک بار دستی درخواست بازبینی کنید. تأیید خودکار فعال و تأیید با دستور نویسنده
غیرفعال است. وضعیت پیشرفت اجرا‌نشده یا محدود به سهمیه، بازبینی واقعی head
فعلی نیست.

بررسی‌های واقعی head فعلی، هویت Appها، بازبینی و دروازهٔ کیفیت Sonar را بررسی
کنید. یک تأیید بومی از شمارش معمول GitHub استفاده می‌کند. ناشر سفارشی یا App
اختصاصی تأیید لازم نیست. [تنظیم Sonar](sonarqube.fa.md) و
[راهنمای مرحله](bootstrap.fa.md) را ببینید. پیش از تغییر مجاز حفاظت در مرحلهٔ
قابل اجرا، اجرای واقعی بررسی جایگزین را مشاهده کنید.
