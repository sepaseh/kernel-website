# صحت فونت محلی

[English](fonts.md) · [فارسی](fonts.fa.md)

منبع متغیر Vazirmatn33.003 با مجوز، خارج از فایل‌های عمومی در font-source/vazirmatn-variable.woff2 نگهداری می‌شود. ۸۱۱ کدپوینت آن بین محدودهٔ CSS لاتین/پایه، عربی/فارسی و باقی‌مانده تقسیم شده است. منبع اصلی سیریلیک ندارد و این مرحله الفبای تازه‌ای اضافه نمی‌کند. فایل public/fonts/OFL.txt مجوز SIL Open Font License را دارد.

اندازهٔ زیرمجموعه‌های تولیدی به‌ترتیب ۳۲۳۹۲، ۴۴۱۸۸ و ۲۴۱۶۸ بایت است. manifest هش، اندازه، محدوده، محور و نسخهٔ ابزار منبع و خروجی را ثبت می‌کند. محدوده‌های CSS بدون اشتراک و کامل‌اند؛ باینری‌ها می‌توانند فاصلهٔ پشتیبان مشترک برای شکل‌دهی داشته باشند. وزن۱۰۰–۹۰۰، نام copyright و مجوز و قابلیت شکل‌دهی استاندارد fontTools حفظ می‌شوند. ویژگی اختیاری اعداد یا سبک ثبت‌شده در manifest پیش از استفاده به تولید دوبارهٔ مجاز نیاز دارد.

## بررسی الزامی

Python3.14.4 را در محیط موقت تازهٔ فعال‌شده‌ای خارج از checkout استفاده کنید. font-source/requirements.txt شامل fonttools4.67.0، Brotli1.2.0 و coverage7.17.0 را نصب کنید. گیت معمول npm run validate -- full شامل npm run check:fonts است؛ CI و scanner همین وابستگی‌ها را بی‌شرط نصب می‌کنند.

check:fonts منبع کامل واقعی را با fontTools باز می‌کند، بخش‌بندی cmap را می‌سازد، با recalcTimestamp:false زیرمجموعه می‌گیرد، باقی‌ماندن کدپوینت تعیین‌شده و برابری محور وزن و متادیتای copyright/مجوز منبع را می‌سنجد و سه بافر WOFF2 و CSS و JSON را در حافظه بازتولید می‌کند. حالت --check بایت دقیق فایل commitشده را مقایسه می‌کند و خروجی قدیمی را شکست می‌دهد؛ فایل را بازنویسی نمی‌کند.

تست مالک در Node به‌طور مستقل هش و اندازهٔ منبع و خروجی، حضور مجوز، تک‌تک محدوده‌های CSS از نظر اشتراک و پوشش کامل، بودجه و preload ده زبان را بررسی می‌کند. preload همیشه لاتین و فقط برای fa/ar عربی را انتخاب می‌کند. این سیاست انتخاب است و بارگذاری اندازه‌گیری‌شدهٔ مرورگر نیست.

پوشش واقعی خط و شاخهٔ Python در coverage/fonts/coverage.xml ساخته و وارد سونار می‌شود؛ گزارش TypeScript و گردش‌کار جدا باقی می‌ماند. استثنای سورس، امنیت یا پوشش تازه‌ای اضافه نمی‌شود. manifest و CSS تولیدی فقط از قالب‌بندی کنار گذاشته شده‌اند تا خروجی دقیق ابزار قطعی بماند.

## نگهداری مجاز

فقط پس از تغییر عمدی فونت، python scripts/subset-website-fonts.py را برای بازنویسی خروجی اجرا و سپس گیت کامل را پاس کنید. اعتبارسنجی معمول --check است و فایل قدیمی یا مفقود را برای پنهان‌کردن شکست تولید نمی‌کند. ابزار پین‌شده برای قطعیت بایت لازم است. منبع خارج از public/ بماند و به preload عمومی برنگردد.

اینجا شکل‌دهی مرورگر، ظاهر گلیف، درخواست شبکه یا کارایی چیدمان و فونت تأیید نمی‌شود. مرحلهٔ قابل اجرا باید متن نمایش‌داده‌شده را با منبع کامل مقایسه و بارگذاری EN/FA/TR، متن مخلوط، کاهش حرکت و محتوای بدون JavaScript را بررسی کند. [محدودهٔ پشتیبانی](client-document.fa.md) و [سیاست مرحله](bootstrap.fa.md) را بخوانید.
