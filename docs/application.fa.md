# قرارداد یکپارچه‌سازی برنامه

[English](application.md) · [فارسی](application.fa.md)

ابتدا [نشانگر انتشار](../.github/bootstrap-policy.json)، [بررسی‌های مرجع](../.agents/validation.json) و [راهنمای مرحله](bootstrap.fa.md) را بخوانید. مرحلهٔ application ترکیب کامل قابل اجرا را با `applicationReady:true`، ۴۰۷ فایل سورس و ۹۰ ماژول محصول منتشر می‌کند. نمایهٔ کامل پانزده بررسی الزامی دارد. آمادگی سورس و قرارداد ثبت‌شده، ادعای موفقیت درخت دلخواه، بررسی میزبانی‌شده یا سرویس مستقر نیست.

## ترکیب برنامه

ترکیب چارچوب، CSS و پیکربندی، آزمون و مستندات باهم تحویل می‌شوند. مالکان شامل [چیدمان ریشه](../src/app/layout.tsx)، صفحه‌های عمومی، احراز هویت و حساب و مرزهای خطا در [app](../src/app)، [مسیر API](../src/app/api)، [پراکسی درخواست](../src/proxy.ts)، [پیام‌های درخواست](../src/i18n/request.ts)، [تنظیمات سرور](../src/shared/settings/server.ts) و [پوستهٔ وب‌سایت](../src/website/layouts) هستند. آزمون واحد ترکیب و مبدل mock صریح چارچوب را حفظ می‌کند؛ ساخت واقعی و بررسی مرورگر شاهد مستقل یکپارچگی را فراهم می‌کنند.

زبان و جهت API بدون کش در محدودهٔ درخواست، کاتالوگ کامل محلی و پیام صریح root/auth/account، انتقال کوکی با no-store، nonce تازه و هر دو حالت CSP، مبدأ صریح SEO و فعال‌سازی اختیاری نمایه‌سازی، فونت محلی دارای مجوز، کاهش حرکت، استقلال پوسته و مالکیت نشست و فرم را حفظ کنید. یک بستهٔ مستقل قابل نصب بدون وابستگی منبع به مخزن دیگر بماند. API نسخهٔ نصب‌شدهٔ چارچوب را بررسی و ترکیب واقعی، مسیر شکست آداپتور، همهٔ صاحبان TS/TSX محصول و مرز import را آزمون کنید. اصلاح امنیتی، آزمون موجود و آستانهٔ پوشش حفظ شود.

## پذیرش روی درخت دقیق

نمایهٔ کامل قابل اجرا پانزده بررسی الزامی ثبت می‌کند: یازده بررسی حفظ‌شده به‌اضافهٔ تحلیل کد بلااستفاده، ساخت تولید با بودجهٔ بسته، مسیر مرورگر شامل CSP اجرایی و گزارش‌محور و مقایسهٔ بصری. فهرست مرجع، نماهای کنترل‌شده، موجودی دقیق، مجوز بسته، تنظیم نوع، lint و پوشش و آزمون معنایی CI باید سازگار باشند. فرمان‌ها از فهرست مرجع و اسکریپت بسته، از جمله `check:unused`، `build`، `test:e2e` و `test:visual` می‌آیند؛ این سند فهرست فرمان مستقل ثبت نمی‌کند.

وابستگی Node و Python تثبیت‌شده را روی خروجی جداشدهٔ درخت دقیق پیشنهادی از نو نصب کنید. برای شاهد مرورگر، نسخهٔ عمومی API و وابستگی‌های آن را طبق [قرارداد fixture](api-fixture.fa.md) مستقل نصب کنید؛ دادهٔ تازهٔ متعلق به آزمون و کلید تولیدشدهٔ صرفاً آزمایشی بیرون منبع، مقصد صریح loopback و هویت SDK و مرورگر تأییدشده استفاده شود. API موجود، dotenv خصوصی یا دادهٔ اپراتور را دوباره استفاده نکنید.

شناسهٔ منبع و درخت، ساخت واقعی تولید و بودجه، نتیجهٔ مرورگر و CSP، شکست و مورد ردشده، مقایسهٔ فعلی تصویر، پوشش و پاک‌سازی را ثبت کنید. نشانگر، گزارش تاریخی، head قبلی یا بستهٔ توسعهٔ جداگانه موفقیت همان درخت انتشار را ثابت نمی‌کند.

## پذیرش بصری و میزبانی‌شده

از مبنای تصویر سازگار و فرادادهٔ ثبت‌شدهٔ سکو، مرورگر، فونت و پیکربندی استفاده کنید. بایت و تاریخ نسخهٔ اولیه حفظ شود. تغییر مبنا نیازمند مجوز صریح و بازبینی بصری واقعی است؛ برای پنهان کردن شکست آن را خودکار عوض نکنید. برای تغییر قابل مشاهدهٔ رابط تصویر واقعی ارائه کنید. نبود شاهد بصری همچنان مانع است.

پیش از هر ادغام برنامهٔ قابل اجرا، اجرای واقعی `check`، `build`، `e2e` و `visual` روی head فعلی همراه با شاهد scanner، Sonar بومی و CodeRabbit مشاهده شود. build/e2e/visual واقعی را با [تغییر حفاظت](branch-protection.fa.md) دارای مجوز صریح الزامی کنید و دیگر حفاظت‌ها، تأیید head فعلی و حل گفتگوها را نگه دارید.

[پیش‌بررسی CodeRabbit](sonarqube.fa.md) را رعایت کنید: همهٔ بررسی‌های الزامی غیر CodeRabbit و گزارش کامل متناظر Sonar با صفر مسئلهٔ حل‌نشده، حداقل یک ساعت از آخرین درخواست و آخرین بازبینی واقعی، محدودیت طولانی‌تر ارائه‌دهنده و نبود درخواست تکراری در جریان. هم‌زمان تنها یک PR وب‌سایت باز باشد و PR مجاز آمادهٔ بازبینی ساخته شود.

## مرز انتشار

پس از ادغام واقعی مجاز، main واقعی را با مبنای آماده‌شده تطبیق دهید و با هر تغییر بایت پیشنهادی پذیرش کامل را دوباره اجرا کنید. هر بستهٔ منسجم حداکثر ۱۰۰ ورودی GitHub داشته باشد؛ برای جا شدن، آزمون یا سند لازم را حذف یا پذیرش زمان اجرا را جدا نکنید.

پذیرش برنامه مجوز استقرار، اجرای workflow، ساخت انتشار یا دسترسی تولید نیست. راه‌اندازی Docker و Lighthouse و عملیات، پذیرش مستقل [تحویل](deployment.fa.md)، [عملیات](release-operations.fa.md) و [staging](staging.fa.md) را دارند. [QA تاریخ‌دار](README.fa.md) تاریخی باقی می‌ماند.
