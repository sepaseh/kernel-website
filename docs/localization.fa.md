# ترجمه‌های وب‌سایت

[English](localization.md) · [فارسی](localization.fa.md)

کاتالوگ کامل محلی، فهرست سادهٔ بارگذاری تنبل و انتخاب صریح پیام کلاینت، قرارداد
ترجمه را تعریف می‌کنند. مؤلفهٔ محلی در تست جداگانه از next-intl واقعی استفاده
می‌کند. [نشانگر انتشار](../.github/bootstrap-policy.json) را بخوانید: در حالت
`applicationReady:false` این تست، آداپتر Next.js وابسته به درخواست، provider
برنامه یا صفحهٔ مرورگر را اجرا نمی‌کند. [قرارداد برنامه](application.fa.md) از
این مالک‌ها می‌خواهد همان مرجع API و مرز پیام کلاینت را حفظ کنند.

## مالکیت کاتالوگ‌ها

[`localeCodes`](../src/i18n/catalog-data/locales.ts) ده کد پشتیبانی‌شدهٔ
`ar`، `de`، `en`، `es`، `fa`، `fr`، `it`، `pt`، `ru` و `tr` را ثبت می‌کند.
هر زبان دقیقاً یک فایل هم‌نام کد خود در
[`src/i18n/catalog-data/locales`](../src/i18n/catalog-data/locales/) دارد.
هر کاتالوگ ۱۰۷ مقدار رشته‌ای تخت و غیرخالی با کلیدهای معنایی یکسان صادر می‌کند.
معنای مشترک، یک کلید ریشه مانند `login` یا `password` دارد؛ معناهای جدا کلیدهای
خود، مانند `accountEmail` و `accountEmailLabel`، را نگه می‌دارند. شیء تودرتوی
`common`، نام مستعار نقطه‌دار یا منبع موازی ترجمه اضافه نکنید.

نوع [`WebsiteTranslationResource`](../src/i18n/catalog-data/website-types.ts)
شکل کامل کلیدها را با import صرفاً نوع از کاتالوگ انگلیسی می‌گیرد. انگلیسی
مالک شکل نوع است و نباید به‌عنوان spread جایگزین ترجمهٔ زبان دیگر شود. ماژول
داده فقط نوع محلی حذف‌شونده در زمان اجرا را import می‌کند؛ import اجرایی
انگلیسی، چارچوب، موتور ترجمه و آداپتر قابلیت در این بخش ممنوع است.
[`catalogs`](../src/i18n/catalogs.ts) برای هر کد ثبت‌شده، بارگذار صریح دارد
و همان شیء اصلی کاتالوگ importشده را دوباره استفاده می‌کند.

ترجمهٔ واقعی، شکست خط عمدی و نام متغیرهای ICU به شکل `{variable}` را در تمام
زبان‌ها حفظ کنید. برای نمونه، `accountTitle` متغیر `{name}`،
`accountVerifiedEmail` متغیر `{email}` و `feedbackResendIn` متغیر `{seconds}`
دارد. این پیام‌ها ICU وب‌سایت هستند. [تست واقعی ICU](../src/i18n/catalogs.test.ts) همهٔ پیام‌ها را با next-intl نصب‌شده parse و interpolate می‌کند؛ این شاهد رفتار موتور است و نمایش فریم‌ورک یا مرورگر را ثابت نمی‌کند.

## زبان فعال و جهت

تنظیمات عمومی API مستقل، تنها زبان فعال و جهت آن را تعیین می‌کند.
[`loadWebsiteLanguage`](../src/shared/settings/language.ts) موجود، بدون
cache و بدون cookie یا هدر زبان بازدیدکننده تنظیمات عمومی را می‌خواند، کد
پشتیبانی‌شده را اعتبارسنجی و جهت صریح `ltr` یا `rtl` از API را می‌پذیرد.
کد کاتالوگ تعیین‌کنندهٔ جهت نیست. تنظیمات پشتیبانی‌نشده، نامعتبر یا در دسترس
نبوده همچنان خطای صریح دارند.

وب‌سایت انتخاب زبان برای بازدیدکننده، cookie زبان یا زبان ذخیره‌شده در
local storage ندارد. فهرست بارگذار فقط دادهٔ پیام کد از قبل انتخاب‌شده را
می‌دهد؛ زبان را مذاکره یا تنظیم سرور را تغییر نمی‌دهد. مالکیت قرارداد API و
کاتالوگ محلی را جدا نگه دارید.

## اعتبارسنجی و کار اجرایی باقی‌مانده

[تست کاتالوگ](../src/i18n/catalog-data/integrity.test.ts) هر ده کاتالوگ واقعی
را بارگذاری می‌کند و مالکیت فایل، ۱۰۷ کلید تخت و کامل، مقدار ترجمهٔ غیرخالی،
برابری متغیر و شکست خط، برچسب معنایی مرجع و یکسان بودن شیء import تکراری را
می‌سنجد. بررسی تفاوت ترجمه، نسخهٔ جایگزین انگلیسی را تشخیص می‌دهد و ارزیابی
کیفیت زبانی نیست.

محافظ انتشار دقیق، تمام کاتالوگ‌ها، نوع، فهرست بارگذار، تست و این راهنمای
دوزبانه را الزامی می‌کند. بررسی مرز سورس، import اجرایی داده، بستهٔ خارجی،
آداپتر منتشرنشده و وابستگی به checkout دیگر را رد می‌کند.
[گیت کامل مرجع](../.agents/validation.json) در هر PR با محدودهٔ اعلام‌شده اجرا
می‌شود: یازده بررسی پیش‌نیاز با نشانگر false و هر پانزده بررسی فعال‌سازی برنامه.
پوشش واقعی واحد و گردش‌کار همهٔ ماژول‌های اجرایی منتشرشده حفظ شود.

[انتخاب پیام کلاینت](../src/i18n/client-messages.ts) و تست مالک، مرز کلید صریح root/auth/account، حفظ کلید مشترک و رد مقدار مفقود یا تودرتو را برای ده زبان می‌سنجند. [تست محلی رابط و نشست](client-ui.fa.md) provider واقعی next-intl را با دادهٔ مصنوعی انگلیسی و فارسی اجرا می‌کند. تست فرم قابلیت از [پیام‌های محدود fixture](../src/test/feature-session.tsx) با انتخاب صریح auth/account استفاده می‌کند تا کاتالوگ کامل، کلید کلاینت مفقود را پنهان نکند. اتصال درخواست Next.js، provider برنامه و صفحهٔ خطای راه‌اندازی باید همین قرارداد دادهٔ محلی را مصرف کنند. اعتبارسنجی مرورگر، دسترس‌پذیری و تصویر بازبینی‌شده به اجرای واقعی مجموعهٔ دقیق قابل اجرا با [API مصنوعی مستقل و پین‌شده](api-fixture.fa.md)، شامل خطای تنظیم ناموجود و جهت داده‌شدهٔ API، نیاز دارد.
