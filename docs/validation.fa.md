# اعتبارسنجی مرجع وب‌سایت

[English](validation.md) · [فارسی](validation.fa.md)

[.agents/validation.json](../.agents/validation.json) تنها فهرست فرمان و نمایه است. [نشانگر منبع](../.github/bootstrap-policy.json) مرحله را تعیین می‌کند؛ settings.recommendedChecks نمای کنترل‌شدهٔ نمایهٔ کامل است. [مشارکت](../CONTRIBUTING.fa.md) صاحب نصب، مجوز و تحویل درخت دقیق است. [آزمون](testing.fa.md) صاحبان اندازه‌گیری‌شده و شواهد را نگاشت می‌کند.

از Node تثبیت‌شده و npm همراه، Python3.14.4 و وابستگی تثبیت‌شدهٔ فونت در محیط Python دورریختنی بیرون منبع استفاده کنید. پس از نصب تازه نمایهٔ کامل را روی خروجی جداشدهٔ درخت دقیق پیشنهادی اجرا کنید:

```sh
npm run validate -- full
```

اجراکننده کل برنامه را اعتبارسنجی می‌کند، شناسهٔ تکراری، حذف الزامی یا جایگزین دستی و پیشنهادی را رد می‌کند، ترتیبی اجرا می‌شود و در شکست می‌ایستد. هر PR شامل مستندات و پیش‌نویس نمایهٔ کامل همان مرحله را بدون فیلتر مسیر اجرا می‌کند. آزمون کوچک توسعه جایگزین آن نیست.

## نسخهٔ فعلی برنامه

مرحلهٔ application پانزده بررسی ثبت می‌کند و همهٔ ۹۰ ماژول محصول را اندازه می‌گیرد. هر دو پروژهٔ TypeScript محصول و ابزار الزامی‌اند. پس از یازده بررسی حفظ‌شده، تحلیل کد بلااستفاده، ساخت تولید و بودجه، مسیر مرورگر و CSP و مقایسهٔ تصویر به ترتیب مرجع اجرا می‌شوند. نوع‌سنجی SDK نصب‌شده و راهبری Node از اجرای واقعی مرورگر جدا می‌مانند. آزمون audit در صاحب واحد اندازه‌گیری‌شدهٔ Vitest می‌ماند.

همهٔ تحلیل و پوشش محصول، آستانهٔ ۹۰٪ چهار سنجهٔ واحد، ۸۰٪ راهبری و سلامت واقعی فونت با پوشش Python حفظ شود. CI باید وابستگی Python تثبیت‌شده را نصب و نمایهٔ کامل را اجرا کند؛ scanner باید پیش از تحلیل پوشش واقعی فونت بسازد. بستهٔ مصنوعی و listener سلامت متعلق به آزمون رفتار ابزار را می‌سنجد و ساخت برنامه یا استقرار نیست.

ورودی اصلی پیش از تنظیم، وابستگی، شبکه یا فایل خروجی آمادگی می‌خواهد. برای اجرا نشانگر false منبع را تغییر ندهید. مورد مثبت محافظ از ریشهٔ مصنوعی صریحاً آمادهٔ متعلق به خود، مقدار عمومی و callback تزریقی استفاده می‌کند. [قرارداد API](api-fixture.fa.md) انتخاب صریح، نسخهٔ ثابت، هویت مستقل وابستگی و دادهٔ تازه می‌خواهد؛ اجرای واقعی API و مرورگر از آزمون Node و ساختگی جداست. dotenv خصوصی، سرویس موجود و انتخاب ضمنی مخزن همسایه مجاز نیست.

## گذار قابل اجرا و شواهد میزبانی‌شده

[یکپارچه‌سازی برنامه](application.fa.md) همهٔ پانزده بررسی ثبت‌شده و ترکیب تحویل‌شده را نگاشت می‌کند. اجراکنندهٔ کامل، ساخت واقعی تولید و بودجه، مسیر مرورگر در هر دو حالت CSP و مقایسهٔ تصویری سازگار را اجرا می‌کند. ورودی مصنوعی صریح و API و مرورگر نسخه‌ثابت مستقل نصب‌شده را مطابق [README](../README.fa.md) و [قرارداد fixture](api-fixture.fa.md) فراهم کنید. نشانگر آماده و سناریوی نوشته‌شدهٔ نوع‌سنجی‌شده جای نتیجهٔ اجرای مشاهده‌شده را نمی‌گیرد.

پیش از ادغام قابل اجرا، کار واقعی build/e2e/visual معرفی و موفقیت head پیشنهادی مشاهده شود و نام واقعی آن‌ها با مجوز صریح الزامی گردد. [حفاظت معمول](branch-protection.fa.md)، تأیید و حل گفتگوها حفظ شود.

موفقیت محلی موفقیت CI، Sonar یا CodeRabbit میزبانی‌شده را ثابت نمی‌کند. پیش از درخواست، [پیش‌بررسی head دقیق](sonarqube.fa.md) شامل گزارش کامل متناظر همهٔ شدت‌های Sonar با صفر مسئلهٔ حل‌نشده، فاصلهٔ زمانی و نبود درخواست تکراری رعایت شود. منبع و درخت واقعی، شکست و موارد ردشده و محدودیت را ثبت کنید. نبود شاهد و audit در دسترس‌نبودن موفقیت نیست؛ گزارش تاریخی و hook اختیاری اعتبارسنجی کامل نیست.
