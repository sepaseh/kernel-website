# اعتبارسنجی مرجع پایهٔ مرورگر

[English](validation.md) · [فارسی](validation.fa.md)

[.agents/validation.json](../.agents/validation.json) تنها فهرست دستور و پروفایل
است. **browser-foundation** یازده بررسی الزامی را روی فهرست دقیق ۳۴۵فایلی غیرقابل اجرا
حفظ می‌کند. چهار ابزار یکپارچه‌سازی حفظ‌شده با سه فایل آزمون مالک Node و هشت ابزار
تحویل با شش فایل آزمون مالک Node در پوشش الزامی گردش‌کار می‌مانند و مورد توصیه‌ای
اجرانشده نیستند. یازده مورد رگرسیون audit موجود در مجموعهٔ واحد Vitest می‌مانند و
اجراکننده و مالک پوشش آن‌ها تغییر نمی‌کند. settings.recommendedChecks بازتاب
بررسی‌شدهٔ full است.
[مشارکت](../CONTRIBUTING.fa.md) مرجع نصب، مجوز و تحویل درخت دقیق است.

دستور الزامی `typecheck` هر دو پروژهٔ `tsconfig.json` و
`tsconfig.tooling.json` را با وابستگی نصب‌شده بررسی می‌کند. پروژهٔ دوم هر سیزده
فایل TypeScript آزمون نوشته‌شده زیر e2e و چهار پیکربندی Playwright را بررسی
می‌کند؛ کامپایل، مرورگر، API یا مسیر تعاملی را اجرا نمی‌کند.

Node پین‌شده و npm همراه آن، و Python3.14.4 با وابستگی پین‌شدهٔ فونت را در
محیط موقت خارج از checkout به‌کار ببرید. پس از نصب تازه، گیت کامل را روی
مجموعهٔ دقیق پیشنهادی جداگانه اجرا کنید:

```sh
npm run validate -- full
```

اجراکننده کل برنامهٔ دستورها را بررسی و به‌ترتیب اجرا می‌کند و با شکست
می‌ایستد. هر PR شامل مستندات و پیش‌نویس همین full را بدون فیلتر مسیر اجرا
می‌کند. پروفایل محدود ثبت‌شده یا آزمون محدود ابزار، شاهد توسعه است و جای full نیست:

```sh
node --test scripts/api-repository.test.mjs scripts/website-performance.test.mjs scripts/visual-environment.test.mjs
```

فایل مالک تحویل مرتبط را از [آزمون](testing.fa.md) انتخاب کنید؛ برای نمونه:

```sh
node --test scripts/release-files.test.mjs scripts/prepare-standalone.test.mjs scripts/package-release.test.mjs
```

این فرمان محدود Node رگرسیون audit مربوط به Vitest یا تمام gate را اجرا نمی‌کند.
برای شاهد کامل تحویل از پروفایل کامل مرجع استفاده کنید؛ برای موفق‌کردن اجراکننده،
selector موجود را حذف یا سورس را از پوشش خارج نکنید.

سورس اجرایی در تحلیل و پوشش واقعی، حداقل واحد ۹۰٪، گردش‌کار ۸۰٪ و بررسی
الزامی واقعی فونت حفظ شوند. fixture مصنوعی bundle و بررسی listener متعلق به
آزمون در loopback فقط رفتار ابزار را می‌سنجند. برنامه نمی‌سازند، API یا
مرورگر راه نمی‌اندازند و تصویر مقایسه نمی‌کنند. در این مرحله دستور نصب‌شدهٔ
مرورگر، Lighthouse، Knip یا استقرار وجود ندارد.

CLI اصلی تحویل سیاست عمومی آمادگی بدون لینک را می‌خواند و مرحلهٔ
applicationReady:false فعلی را پیش از عملیات تنظیم، شبکه یا artifact رد می‌کند.
ریشهٔ ساختگی آزمون می‌تواند آمادگی را اعلام کند تا کپی محلی واقعی و بسته‌بندی
غیرقابل‌بازنویسی بررسی شود؛ marker برنامهٔ سالم را ثابت نمی‌کند. مقدار عمومی
پیکربندی، callback تزریقی engine و listener سلامت متعلق به آزمون، شاهد را محلی
نگه می‌دارد. قالب غیرفعال native و Docker، پیکربندی نسخه و مدخل تاریخی changelog
گردش‌کار ارائه‌دهنده یا استقرار را فعال نمی‌کنند.
[پذیرش تحویل](deployment.fa.md) و [عملیات](release-operations.fa.md) را ببینید.

ابزار محل API به KERNEL_SYNTHETIC_ENV=1 و KERNEL_API_DIRECTORY مطلق صریح
نیاز دارد؛ آزمون پوشهٔ مصنوعی متعلق به خود را می‌دهد. بررسی نشانهٔ پروژه،
نصب، revision تغییرناپذیر یا سازگاری سرویس را ثابت نمی‌کند. helper محیط فقط
ضروریات مجاز runtime و مقدار مصنوعی را نگه می‌دارد، نه secret مالک یا
NODE_OPTIONS. dotenv واقعی، دادهٔ موجود یا checkout دیگر را ضمنی بارگذاری نکنید.

نتیجهٔ محلی، اجرای CI میزبانی‌شده، Sonar یا CodeRabbit را ثابت نمی‌کند.
پیش از درخواست سرویس یا ادغام مجاز، [حفاظت شاخه](branch-protection.fa.md) و
[پیش‌شرط head فعلی](sonarqube.fa.md#پیش-از-درخواست-بازبینی-coderabbit) را
رعایت کنید. شکست، شاهد غایب و audit در دسترس‌نبوده موفقیت نیست. هوک اختیاری
کمک میزبان است، نه گیت کامل؛ آزمون fixture در Bash و Node، بارگذاری خودکار
میزبان را ثابت نمی‌کند.

پیش از فعال‌سازی زمان اجرا، برنامه و fixture مصنوعی API مستقل نصب‌شده را
منتشر، بررسی برنامه را گسترش، موفقیت واقعی jobهای build، مرورگر، CSP و تصویر
را مشاهده و context تأییدشدهٔ آن‌ها را الزامی کنید. گزارش تاریخی و metadata
baseline جای این شاهد را نمی‌گیرد.

[پایهٔ اجراکننده‌ها](runner-foundation.fa.md) شش ماژول Node و شش فایل آزمون مالک با پوشش واقعی برای ورودی صریح، چرخهٔ عمر فرزند مستقیم، راه‌اندازی fixture مستقل و API و خروجی محدود تحلیل اضافه می‌کند. عملیات ورودی وب‌سایت، API، سرور و تحلیلگر ابتدا نشانگر عمومی آمادگی را می‌خواند و مجموعهٔ فعلی با applicationReady:false را رد می‌کند. import فایل، dotenv نمی‌خواند، محیط را تغییر نمی‌دهد و سرویسی آغاز نمی‌کند. آزمون‌ها برنامه‌های مصنوعی Node متعلق به خود، شامل خطا و لغو، را اجرا می‌کنند؛ ساخت یا اجرای واقعی Next.js، API مستقل، مرورگر، موتور Docker یا تحلیل آزمایشگاهی اجرا نمی‌شود. دروازهٔ یازده‌بررسی بدون کاهش حد پوشش یا استثنای سورس، ابزار جدید را اندازه می‌گیرد. [پایهٔ مرورگر](browser-foundation.fa.md) اکنون مجموعهٔ آزمون نوشته‌شده با بررسی نوع، پیکربندی Playwright با آمادگی پیش از عملیات و اجرای کنترل‌شدهٔ visual/CSP را اضافه می‌کند. چهار فایل آزمون Node محافظ‌ها و رفتار تزریق‌شده را اندازه می‌گیرند؛ فایل اجرایی مرورگر، API مستقل و اجرای واقعی مرورگر یا مقایسهٔ تصویر همچنان به آینده موکول‌اند.
