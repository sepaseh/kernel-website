# مرحلهٔ پایه

[English](bootstrap.md) · [فارسی](bootstrap.fa.md)

این مرحله دوازده فایل سورس دارد: شش ماژول قرارداد، ابزار فرم و تست، اعتبارسنجی
نشانی API، کد زبان‌ها و خواندن زبان تنظیمات عمومی همراه تست.
[فهرست دقیق](../.github/bootstrap-policy.json) مقدار
`applicationReady:false` را الزامی می‌کند. برنامهٔ Next.js، نمایش ترجمه،
سفر مرورگر، استقرار یا وابستگی زمان اجرا در این مرحله وجود ندارد.

پس از `npm ci`، دستور `npm run validate -- full` را اجرا کنید.
[فهرست مرجع](../.agents/validation.json) هشت بررسی الزامی دارد: مجموعهٔ دقیق،
audit، import بسته، نوع‌ها، lint، قالب‌بندی، تست واحد با پوشش و تست گردش‌کار
با پوشش. پیش از commit، push یا تحویل PR مجاز، تمام مرحلهٔ فعلی را روی مجموعهٔ
دقیق جداگانه اجرا کنید؛ سورس حذف‌شده از این مجموعه در پوشهٔ اصلی شاهد نیست.

پوشش واحد باید برای statement، شاخه، تابع و خط به ۹۰٪ برسد. پوشش گردش‌کار برای
خط، تابع و شاخه، بدون فایل تست، حداقل ۸۰٪ است. گزارش‌ها از اجرای واقعی در
`coverage/unit/lcov.info` و `coverage/governance/lcov.info` ساخته می‌شوند؛
آن‌ها را commit یا جعل نکنید و پوشش وب‌سایت کامل ننامید.

فهرست، فایل اضافه یا مفقود، مسیر خصوصی و لینک نمادین را رد و پیوندهای محلی
مستندات را بررسی می‌کند. پوشه‌های معمول `node_modules` و `coverage` در
ریشه برای خروجی مجازند. سقف ۱۰۰ فایل برای فایل‌های تغییرکردهٔ هر PR است و
تعداد کل فهرست را محدود نمی‌کند.

[CI](../.github/workflows/ci.yml) تمام مرحله و بررسی اندازهٔ PR با دسترسی
فقط‌خواندنی عادی را اجرا می‌کند. main خالی هنوز محافظ مورد اعتماد PR ندارد.
پس از ادغام بازبینی‌شده، [محافظ target](../.github/workflows/pr-policy.yml)
فقط checkout ثابت `github.workflow_sha` را با دسترسی فقط‌خواندنی اجرا می‌کند.
در این رویداد دارای دسترسی، کد head یا مبنای بازبینی‌نشده را اجرا نکنید.
صفحه‌بندی به‌دلیل وابستگی لینک بعد به پاسخ قبلی، ترتیبی است و شاهد ناقص یا
تغییر head و base را رد می‌کند.

از CI، CodeRabbit و Sonar بومی، یک بازبینی تأییدشده و حل گفتگوها استفاده کنید.
بازبینی خودکار CodeRabbit خاموش است؛ فقط پس از تأمین [تمام پیش‌شرط‌ها](sonarqube.fa.md#پیش-از-درخواست-بازبینی-coderabbit) برای head فعلی، دستی درخواست بازبینی کنید. موفقیت تمام بررسی‌های الزامی غیر از CodeRabbit و صفر بودن یافتهٔ OPEN یا حل‌نشده در تمام شدت‌ها الزامی است؛ بررسی محافظت‌شدهٔ برنامه در صورت غیبت نیز مانع است. پس از تغییر head دوباره بررسی کنید، سهمیه را رعایت و درخواست در حال اجرا را تکرار نکنید. [مشارکت](../CONTRIBUTING.fa.md)،
[حفاظت شاخه](branch-protection.fa.md) و [Sonar](sonarqube.fa.md) را ببینید.

الزامات موجود build، e2e و visual برنامهٔ کامل همچنان تأمین نشده‌اند. این
مرحله بررسی ساختگی منتشر نمی‌کند و حفاظت دوردست را تغییر نمی‌دهد. با ورود
برنامهٔ قابل اجرا، build کامل، HTTP و احراز هویت، مرورگر و CSP، دسترس‌پذیری
و تصاویر بازبینی‌شده با fixture مصنوعی جداگانهٔ API اضافه شوند. پیش از مهاجرت
مجاز حفاظت، اجرای واقعی جایگزین را تأیید کنید.
