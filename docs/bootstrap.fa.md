# مرحله‌های انتشار و آمادگی منبع

[English](bootstrap.md) · [فارسی](bootstrap.fa.md)

[سیاست منبع](../.github/bootstrap-policy.json) مرجع مرحله، آمادگی و موجودی دقیق است. مرحلهٔ application-guidance مقدار `applicationReady:false`، همان ۶۶ ماژول محصول، ۳۴ فایل آزمون منبع و سه پشتیبان آزمون را حفظ می‌کند. راهنمای وابسته به مرحله و تاریخچهٔ منبع را بر پیش‌نیاز API-fixture می‌افزاید و مسیر قابل اجرا، چیدمان ریشه یا خط ساخت CSS معرفی نمی‌کند. تعداد موجودی با سقف ۱۰۰ ورودی PR متفاوت است.

## بنیاد تحویل‌شده

[فرم](forms.fa.md)، [رابط کلاینت](client-ui.fa.md)، [نشست](session.fa.md)، [پشتیبانی سند](client-document.fa.md)، [فونت](fonts.fa.md)، [بومی‌سازی](localization.fa.md) و [مرز سرور](server-boundary.fa.md) رفتار منتشرشده را تعریف می‌کنند. React/RTL، Radix، next-intl و next-themes واقعی از jsdom جداشده و HTTP مصنوعی استفاده می‌کنند؛ mock مستند راهبری چارچوب و سند و حرکت حفظ می‌شود. همهٔ TS/TSX محصول اندازه‌گیری می‌شود. فرم‌ها مالکیت نشست، نسل و mount، مقصد OTP و بازخورد محدود 401 عمومی و محافظت‌شده را حفظ می‌کنند.

ابزار [راه‌انداز](runner-foundation.fa.md) و [مرورگر](browser-foundation.fa.md) با import بی‌اثر، عملیات پس از محافظ آمادگی، ورودی صریح و چرخهٔ فرزند متعلق به خود منتشر است. مسیر تألیف‌شده و چهار پیکربندی Playwright نوع‌سنجی می‌شوند؛ fixture Node متعلق به آزمون راه‌اندازی را بررسی می‌کند. [قرارداد API](api-fixture.fa.md) نسخهٔ ثابت، منبع پاک، وابستگی مستقل نصب‌شده، ورودی منتشرشدهٔ API، دادهٔ تازه و تنظیم اصلاح‌شدهٔ راه‌انداز و worker را اضافه می‌کند و فرض قدیمی صرفاً ساختاری را جایگزین می‌سازد. دروازهٔ نشانگر false API، مرورگر، ساخت، تصویر یا استقرار واقعی اجرا نمی‌کند.

[تحویل](deployment.fa.md) و [عملیات](release-operations.fa.md) صاحب ابزار فایل خروجی، تنظیم، سلامت و پاک‌سازی و قالب غیرفعال هستند. مورد مثبت محافظ از ریشهٔ مصنوعی آماده، مقدار عمومی، موتور تزریقی یا listener متعلق به آزمون استفاده می‌کند. نشانگر آزمون داده است و پذیرش برنامه نیست. ورودی اصلی پیش از تنظیم، وابستگی، شبکه یا عملیات فایل خروجی نشانگر false را رد می‌کند.

## شواهد الزامی

[اعتبارسنجی مرجع](../.agents/validation.json) همان یازده بررسی کامل را دارد: snapshot، سیاست CI، راهنما، audit، مرز، نوع، lint، قالب، واحد اندازه‌گیری‌شده، راهبری اندازه‌گیری‌شده و سلامت واقعی فونت. [مشارکت](../CONTRIBUTING.fa.md) پیش از commit، push یا تحویل PR مجاز نصب تازهٔ Node و Python تثبیت‌شده و موفقیت کامل درخت دقیق جداشده را الزامی می‌کند. هر PR از جمله مستندات و پیش‌نویس نمایهٔ کامل همان مرحله را بدون فیلتر مسیر اجرا می‌کند.

آستانهٔ ۹۰٪ چهار سنجهٔ واحد، ۸۰٪ راهبری و حداقل ۸۰٪ پوشش اندازه‌گیری‌شدهٔ فونت حفظ شود. گزارش‌ها تولیدشده می‌مانند: `coverage/unit/lcov.info`، `coverage/governance/lcov.info` و `coverage/fonts/coverage.xml`. آن‌ها را نسازید، منبع تازه را مستثنا و بررسی را تضعیف نکنید. هر دو پروژهٔ TypeScript محصول و ابزار الزامی‌اند. ترتیب نصب و پوشش واقعی فونت در CI و scanner حفظ شود.

## گذار به برنامه

[یکپارچه‌سازی برنامه](application.fa.md) صاحب قرارداد کامل پذیرش مرحلهٔ بعد است. ترکیب واقعی چارچوب، CSS، تنظیم و آزمون آداپتور باهم تحویل شوند، موجودی دقیق منبع و import و پوشش بسته شود و نمایهٔ کامل به هر پانزده بررسی گسترش یابد. ساخت تولید و بودجه، مسیر مرورگر هر دو حالت CSP و مقایسهٔ بصری سازگار نیازمند API مصنوعی مستقل نصب‌شده، دادهٔ تازه و مرورگر تأییدشده است.

پیش از ادغام قابل اجرا، build/e2e/visual واقعی head فعلی مشاهده و با تغییر سیاست دارای مجوز صریح محافظت‌شده شوند. [حفاظت معمول](branch-protection.fa.md)، تأیید head فعلی و حل گفتگوها حفظ شود. نشانگر true، بستهٔ توسعهٔ جدا یا تصویر مبنای تاریخی جای اجرا را نمی‌گیرد.

## راهنما و انتشار

[ناوبری](source-navigation.fa.md) فقط مسیر منتشرشده را فهرست می‌کند. [ارزیابی](comprehension-evaluation.fa.md) بررسی ایستا را از فهم منبع اندازه‌گیری‌شده و کشف میزبان جدا می‌کند. hook اختیاری، آداپتور نازک میزبان و ابزار دستیار وابستگی زمان اجرا یا دروازهٔ کامل نیستند. QA تاریخ‌دار و نسخهٔ اولیهٔ بایگانی‌شده محدوده و تاریخ خود را حفظ می‌کنند.

تنها یک PR وب‌سایت باز باشد. پس از ادغام واقعی مجاز، main واقعی با مبنای آماده مقایسه و با تغییر بایت پیشنهادی پذیرش کامل تکرار شود. هر PR حداکثر ۱۰۰ ورودی GitHub تغییر دهد و PR مجاز آمادهٔ بازبینی باشد. درخواست CodeRabbit به [پیش‌بررسی head دقیق](sonarqube.fa.md)، یک ساعت از آخرین درخواست و آخرین بازبینی واقعی، محدودیت ارائه‌دهنده و نبود درخواست تکراری در جریان نیاز دارد. انتشار به‌تنهایی مجوز عملیات یا تولید نیست.
