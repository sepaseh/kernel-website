# مرحلهٔ انتشار پایهٔ رابط کلاینت

[English](bootstrap.md) · [فارسی](bootstrap.fa.md)

این انتشار غیرقابل اجرا ۵۰ ماژول اجرایی، ۲۴ فایل تست سورس، دو ماژول پشتیبان تست و فهرست دقیق ۱۳۹ فایل نگهداری‌شده دارد. [سیاست](../.github/bootstrap-policy.json) مقدار applicationReady:false، مجموعهٔ کامل سورس و ممنوعیت مسیر خصوصی و symlink را الزامی می‌کند. فقط پوشهٔ معمول node_modules و coverage ریشه خروجی نادیده‌گرفته‌شده‌اند. هر PR حداکثر ۱۰۰ فایل تغییر می‌دهد؛ تعداد کل فهرست مستقل است.

[پایهٔ رابط کلاینت](client-ui.fa.md)، [نشست](session.fa.md)، [پشتیبانی کلاینت و سند](client-document.fa.md)، [فونت](fonts.fa.md)، [ترجمه](localization.fa.md) و [مرز سرور](server-boundary.fa.md) مالکیت را شرح می‌دهند. ابزارهای محلی رابط، provider نشست و پوسته، شمارش معکوس و آداپتر حرکت مستقل قابل‌آزمون‌اند. Next.js نوع حذف‌شوندهٔ سند و آداپتر مستقل هوک Web Vitals را می‌دهد و تست واقعی next-intl اجرای ICU را می‌سنجد. src/app فقط provider ترکیبی و تست مالک آن را دارد؛ صفحه، layout ریشه، آداپتر درخواست صرفاً سروری، خط ساخت CSS، نقطهٔ ورود برنامه، fixture مرورگر یا استقرار وجود ندارد.

[فهرست مرجع](../.agents/validation.json) ده بررسی الزامی دارد: مجموعهٔ دقیق، سیاست معنایی CI، audit، مرز سورس، نوع، lint، قالب‌بندی، واحد با پوشش، گردش‌کار با پوشش و صحت واقعی فونت. پیش از commit، push یا تحویل مجاز، npm ci، نصب [وابستگی‌های Python پین‌شده](../font-source/requirements.txt) با Python3.14.4 و npm run validate -- full را روی درخت دقیق جداگانه اجرا کنید.

هر PR شامل پیش‌نویس همین پروفایل کامل را بدون فیلتر مسیر اجرا می‌کند. شناسهٔ تکراری، بررسی الزامی جامانده یا مورد دستی/توصیه‌ای در full پیش از اجرا رد می‌شود. CI نصب npm در ریشه و اجرای کامل بی‌شرط و نصب Python و وابستگی دقیق را می‌خواهد. scanner پیش از تحلیل باید پوشش واقعی ابزار فونت Python را بسازد؛ تست معنایی، حذف یا شرطی‌کردن، تغییر ترتیب و نادیده‌گرفتن شکست را رد می‌کند.

حداقل پوشش واحد برای هر چهار معیار ۹۰٪ و پوشش گردش‌کار برای خط، تابع و شاخه ۸۰٪ است. ابزار فونت پوشش خط و شاخهٔ اندازه‌گیری‌شده با حداقل ترکیبی ۸۰٪ دارد. گزارش واقعی در coverage/unit/lcov.info، coverage/governance/lcov.info و coverage/fonts/coverage.xml قرار می‌گیرد و commit یا جعل نمی‌شود.

هر ۵۰ ماژول اجرایی TS/TSX صریحاً در پوشش و تحلیل سورس می‌ماند و فایل تست و پشتیبان آن تست طبقه‌بندی می‌شوند. React/RTL، Radix، next-intl و next-themes واقعی در jsdom جداگانه اجرا می‌شوند و fetch و media-query مصنوعی محلی‌اند. تست مالک Motion و هوک فریم‌ورک mock مستند و متن ثابت دارد و شاهد اتصال مرورگر نیست. قواعد پیشنهادی هوک به lint الزامی اضافه شده‌اند؛ مرز دقیق مالک و بسته TSX را شامل می‌شود و نقطهٔ ورود منتشرنشده یا import تست را رد می‌کند.

[حفاظت بومی شاخه](branch-protection.fa.md) همچنان check، PR file limit مورد اعتماد، SonarQube Cloud analysis، SonarCloud Code Analysis و CodeRabbit را می‌خواهد. محافظ اندازهٔ target فقط checkout ثابت workflow خود را با دسترسی فقط‌خواندنی اجرا می‌کند. به‌روز بودن سخت‌گیرانه، تأیید فعلی، حل گفتگو و اعمال حفاظت برای مدیر محفوظ بمانند.

درخواست کدربیت فقط پس از [پیش‌شرط head دقیق و صفر issue](sonarqube.fa.md#پیش-از-درخواست-بازبینی-coderabbit)، فاصلهٔ مجاز مخزن و نبود درخواست تکراری در حال اجرا انجام شود. بازبینی خودکار خاموش می‌ماند و skipped شاهد بازبینی واقعی نیست.

پیش از ادغام برنامهٔ قابل اجرا هر پانزده بررسی برنامه را با fixture مصنوعی API مستقل نصب‌شده منتشر کنید؛ موفقیت واقعی build، e2e و visual را ببینید و الزامی کنید. این مرحله اجرای Next.js، مرورگر، دسترس‌پذیری، تصویر یا استقرار را ثابت نمی‌کند.
