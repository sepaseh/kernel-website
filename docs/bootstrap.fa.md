# مرحلهٔ انتشار پایهٔ اجراکننده‌ها

[English](bootstrap.md) · [فارسی](bootstrap.fa.md)

این انتشار غیرقابل اجرا ۶۶ ماژول اجرایی، ۳۴ فایل تست سورس، سه ماژول پشتیبان تست و فهرست دقیق ۳۱۷ فایل نگهداری‌شده دارد. [سیاست](../.github/bootstrap-policy.json) مقدار applicationReady:false، مجموعهٔ کامل سورس و ممنوعیت مسیر خصوصی و symlink را الزامی می‌کند. فقط پوشهٔ معمول node_modules و coverage ریشه خروجی نادیده‌گرفته‌شده‌اند. هر PR حداکثر ۱۰۰ فایل تغییر می‌دهد؛ تعداد کل فهرست مستقل است.

راهنمای حفظ‌شده شامل قواعد و مهارت قابل‌انتقال، ناوبری صریح سورس و بررسی، نه پرسش انگلیسی با الگوی اجرای انجام‌نشده، هوک اختیاری میزبان و مستند معماری، طراحی و امنیت دوزبانه است. بررسی راهنما مسیر محلی، پیوند نگهداری‌شده، تطابق دستور مرجع و مالکیت مستقل را بررسی می‌کند؛ پاسخ مدل، کامل‌بودن گراف معنایی یا بارگذاری دستور در میزبان را ارزیابی نمی‌کند. تنظیم تولیدکنندهٔ مؤلفه و CSS به آینده موکول است.

[فرم‌ها](forms.fa.md)، [پایهٔ رابط کلاینت](client-ui.fa.md)، [نشست](session.fa.md)، [پشتیبانی کلاینت و سند](client-document.fa.md)، [فونت](fonts.fa.md)، [ترجمه](localization.fa.md) و [مرز سرور](server-boundary.fa.md) مالکیت را شرح می‌دهند. فرم ورود، ثبت‌نام، بازیابی و حساب از ابزار رابط، ماژول HTTP و provider نشست بررسی‌شده استفاده می‌کنند. فرم مشترک OTP قرارداد جداگانهٔ دو قابلیت را حفظ می‌کند؛ آداپتر عملیات mount و ناوبری سند مالک محدود خود را دارند. Next.js مرز link/router مخصوص قابلیت، نوع حذف‌شوندهٔ سند و آداپتر مستقل هوک Web Vitals را می‌دهد و تست واقعی next-intl اجرای ICU را می‌سنجد. src/app فقط provider ترکیبی و تست مالک آن را دارد؛ صفحه، layout ریشه، آداپتر درخواست صرفاً سروری، خط ساخت CSS، نقطهٔ ورود برنامه، fixture مرورگر یا استقرار وجود ندارد.

[فهرست مرجع](../.agents/validation.json) یازده بررسی الزامی دارد: مجموعهٔ دقیق، سیاست معنایی CI، سازگاری راهنما، audit، مرز سورس، نوع، lint، قالب‌بندی، واحد با پوشش، گردش‌کار با پوشش و صحت واقعی فونت. پیش از commit، push یا تحویل مجاز، npm ci، نصب [وابستگی‌های Python پین‌شده](../font-source/requirements.txt) با Python3.14.4 و npm run validate -- full را روی درخت دقیق جداگانه اجرا کنید.

هر PR شامل پیش‌نویس همین پروفایل کامل را بدون فیلتر مسیر اجرا می‌کند. شناسهٔ تکراری، بررسی الزامی جامانده یا مورد دستی/توصیه‌ای در full پیش از اجرا رد می‌شود. CI نصب npm در ریشه و اجرای کامل بی‌شرط و نصب Python و وابستگی دقیق را می‌خواهد. scanner پیش از تحلیل باید پوشش واقعی ابزار فونت Python را بسازد؛ تست معنایی، حذف یا شرطی‌کردن، تغییر ترتیب و نادیده‌گرفتن شکست را رد می‌کند.

حداقل پوشش واحد برای هر چهار معیار ۹۰٪ و پوشش گردش‌کار برای خط، تابع و شاخه ۸۰٪ است. ابزار فونت پوشش خط و شاخهٔ اندازه‌گیری‌شده با حداقل ترکیبی ۸۰٪ دارد. گزارش واقعی در coverage/unit/lcov.info، coverage/governance/lcov.info و coverage/fonts/coverage.xml قرار می‌گیرد و commit یا جعل نمی‌شود.

هر ۶۶ ماژول اجرایی TS/TSX صریحاً در پوشش و تحلیل سورس می‌ماند و فایل تست و پشتیبان آن تست طبقه‌بندی می‌شوند. React/RTL، Radix، next-intl و next-themes واقعی در jsdom جداگانه اجرا می‌شوند و fetch و media-query مصنوعی محلی‌اند. تست مالک Motion و هوک فریم‌ورک mock مستند و متن ثابت دارد و شاهد اتصال مرورگر نیست. قواعد پیشنهادی هوک به lint الزامی اضافه شده‌اند؛ مرز دقیق مالک و بسته TSX را شامل می‌شود و نقطهٔ ورود منتشرنشده یا import تست را رد می‌کند.

تست قابلیت از انتخاب صریح پیام auth/account، کلاینت HTTP و SessionProvider واقعی استفاده می‌کند. فقط ناوبری router فریم‌ورک و سند mock می‌شوند؛ این تست اعتبارسنجی محلی، وضعیت مشغول/خطا/تلاش مجدد، مقصد OTP و مالکیت نشست/mount را می‌سنجد، نه ناوبری Next.js، اعتبارسنجی مرورگر یا کوکی. همهٔ فرم‌های قابلیت با نسل تازهٔ نشست، زبان یا هویت حساب بازنشانی می‌شوند. پاسخ ۴۰۱ احراز هویت عمومی، بدون اعلان پایان نشست، بازخورد فرم آغازکننده را نگه می‌دارد؛ اعلان ۴۰۱ محافظت‌شده حفظ می‌شود. [قواعد مالکیت](session.fa.md) را بخوانید.

[حفاظت بومی شاخه](branch-protection.fa.md) همچنان check، PR file limit مورد اعتماد، SonarQube Cloud analysis، SonarCloud Code Analysis و CodeRabbit را می‌خواهد. محافظ اندازهٔ target فقط checkout ثابت workflow خود را با دسترسی فقط‌خواندنی اجرا می‌کند. به‌روز بودن سخت‌گیرانه، تأیید فعلی، حل گفتگو و اعمال حفاظت برای مدیر محفوظ بمانند.

درخواست کدربیت فقط پس از [پیش‌شرط head دقیق و صفر issue](sonarqube.fa.md#پیش-از-درخواست-بازبینی-coderabbit)، فاصلهٔ مجاز مخزن و نبود درخواست تکراری در حال اجرا انجام شود. بازبینی خودکار خاموش می‌ماند و skipped شاهد بازبینی واقعی نیست.

پیش از ادغام برنامهٔ قابل اجرا هر پانزده بررسی برنامه را با fixture مصنوعی API مستقل نصب‌شده منتشر کنید؛ موفقیت واقعی build، e2e و visual را ببینید و الزامی کنید. این مرحله اجرای Next.js، مرورگر، دسترس‌پذیری، تصویر یا استقرار را ثابت نمی‌کند.

هوک ایمنی و پس‌ازویرایش، ابزار اختیاری وابسته به میزبان‌اند. هوک ایمنی الگوهای شناخته‌شدهٔ دستور و مسیر را می‌سنجد؛ همهٔ نحوهای پوسته یا اجازهٔ قبلی کاربر را نمی‌فهمد. قالب‌بندی محدود پس‌ازویرایش فقط فایل تأییدشدهٔ داخل همان پوشهٔ کاری را تغییر می‌دهد. کمک‌کنندهٔ کیفیت، نوع و lint را اجرا می‌کند؛ تنها پروفایل کامل مرجع شاهد تحویل است. آزمون قابل‌انتقال Bash از پروژهٔ موقت مصنوعی و متعلق به آزمون استفاده می‌کند.

ابزارهای یکپارچه‌سازی حفظ‌شده، راهنما را با چهار ابزار مستقل کیفیت و سه فایل آزمون مالک در Node گسترش می‌دهد. تعیین‌کنندهٔ صریح مسیر API فقط fixture مصنوعی انتخاب‌شده را بررسی می‌کند؛ آزمون بسته نمودار ساخت مصنوعی می‌سازد؛ آزمون محیط کارایی و فراداده و قفل بصری از فایل‌های موقت متعلق به خود استفاده می‌کند. این موارد بدون بستهٔ جدید، نقطهٔ ورود اجرایی یا کاهش دروازه به پوشش الزامی گردش‌کار می‌پیوندند. هفت جفت راهنمای کیفیت، رفتار ابزار تحویل‌شده را از پذیرش آیندهٔ مرورگر و برنامه جدا می‌کنند. دروازهٔ این مرحله هیچ فرایند API، مرورگر، منبع Docker یا ساخت برنامه‌ای را آغاز نمی‌کند.

مرحلهٔ ابزارهای تحویل هشت ابزار Node، شش فایل آزمون مالک، چهار نمونهٔ عمومی محیط، قالب غیرفعال Docker و بومی و راهنمای دوزبانهٔ تحویل و امنیت اضافه می‌کند. فهرست بسته، گردش‌کار موجود CI، سیاست و Sonar را حفظ می‌کند، اما گردش‌کار عملیاتی جدید، اجراکنندهٔ مرورگر یا نقطهٔ ورود برنامه را نمی‌پذیرد. CLIها پیش از خواندن تنظیمات، بررسی مقصد یا عملیات دارایی، مرحلهٔ false فعلی را رد می‌کنند؛ فقط ریشهٔ مصنوعی متعلق به آزمون می‌تواند نشانگر صریح آماده داشته باشد تا رفتار محلی واقعی بررسی شود. عملیات بسته و کپی، مجموعهٔ واقعی runtime مستقل، ساخت کانتینر، سرویس TLS یا استقرار را ثابت نمی‌کند. سابقهٔ تغییرات و فرادادهٔ نسخهٔ واردشده، تاریخی یا تنظیم آماده‌سازی است. دروازهٔ کامل یازده‌بررسی موارد جدید Node را شامل می‌شود و رگرسیون audit موجود را در مجموعهٔ واحد Vitest حفظ می‌کند.

[پایهٔ اجراکننده‌ها](runner-foundation.fa.md) شش ماژول Node و شش فایل آزمون مالک با پوشش واقعی برای ورودی صریح، چرخهٔ عمر فرزند مستقیم، راه‌اندازی fixture مستقل و API و خروجی محدود تحلیل اضافه می‌کند. عملیات ورودی وب‌سایت، API، سرور و تحلیلگر ابتدا نشانگر عمومی آمادگی را می‌خواند و مجموعهٔ فعلی با applicationReady:false را رد می‌کند. import فایل، dotenv نمی‌خواند، محیط را تغییر نمی‌دهد و سرویسی آغاز نمی‌کند. آزمون‌ها برنامه‌های مصنوعی Node متعلق به خود، شامل خطا و لغو، را اجرا می‌کنند؛ ساخت یا اجرای واقعی Next.js، API مستقل، مرورگر، موتور Docker یا تحلیل آزمایشگاهی اجرا نمی‌شود. دروازهٔ یازده‌بررسی بدون کاهش حد پوشش یا استثنای سورس، ابزار جدید را اندازه می‌گیرد. SDK و مجموعهٔ آزمون مرورگر و فعال‌سازی برنامه، کار آینده‌اند.
