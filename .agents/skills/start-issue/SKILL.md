# Start an issue

Read [issues](../../rules/issues.md), [branches](../../rules/branches.md),
[Git policy](../../rules/git.md) and [safety](../../rules/safety.md).

1. Verify the actual issue, evidence, current source and acceptance criteria.
2. Identify published owners and checks through [navigation](../../navigation.json).
3. Inspect status and preserve unrelated work; reuse the existing checkout and a suitable branch.
4. Implement the authorized local scope and use [validate-change](../validate-change/SKILL.md).
5. Report changes, evidence and limits. Do not invent issue metadata, publish comments,
   assign/close the issue, commit, push or open a PR without corresponding authorization.
