# Review a pull request

Read [code-review rules](../../rules/code-review.md), [Git policy](../../rules/git.md)
and [PR policy](../../rules/pull-requests.md).

1. Verify repository, PR, head/base, acceptance criteria and complete diff.
2. Inspect affected owners, tests, checks and guidance.
3. Report actionable findings first, with tight locations and concrete failure scenarios.
4. Distinguish local checks, hosted results, provider analysis and actual approval.
5. Submit a remote review only when authorized.
6. Before any CodeRabbit request, complete [current-head preflight](../../../docs/reviews.md).
   Do not resolve threads or merge without separate authorization.
