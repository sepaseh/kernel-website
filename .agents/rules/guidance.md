# Guidance and evidence

Maintain assistant instructions and human Markdown in English.
Keep human guides flat, task-oriented and linked to their owning procedure.
Update existing guidance when behavior changes; do not add dated QA reports or ADRs.

Register only published owners, tests, rules, skills and actual check IDs.
All local links must resolve in the current declared inventory.
Check examples against source and exercise safe local commands when changing them.
Keep repeated policy in its canonical owner and link to it.

Report execution outcomes in the current task or terminal. Save a local report
only on explicit request under ignored `test-results/`.
An index or successful guidance check proves structure, not host loading,
model comprehension, provider analysis or application readiness.
