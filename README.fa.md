# Kernel Website

[English](README.md) · [فارسی](README.fa.md)

این پروژهٔ مستقل TypeScript در مرحلهٔ **پایه** است و مقدار
`applicationReady` همچنان **false** است. محدودهٔ فعلی ده ماژول اجرایی و دو
فایل تست دارد:

- شش ماژول خالص قرارداد در `src/shared/contracts`، فایل‌های `types.ts`
  متعلق به قابلیت‌ها و `src/shared/settings/contracts.ts`.
- ابزار ورودی فرم با حفظ فاصله‌های رمز عبور و یکسان‌سازی رقم‌های تلفن همراه.
- اعتبارسنجی امن نشانی API و خواندن تنظیمات عمومی بدون cache، با حفظ زبان
  فعال و جهت اعلام‌شدهٔ سرور.
- فهرست کد زبان‌ها؛ کاتالوگ ترجمه و نمایش آن در این مرحله وجود ندارد.

رابط React/Next.js، مسیرهای برنامه، آداپتر ترجمه، آزمون مرورگر و استقرار در این
مرحله وجود ندارند. وابستگی زمان اجرا تعریف نشده است.
[فهرست دقیق فایل‌ها](.github/bootstrap-policy.json) را ببینید.

## نصب و اعتبارسنجی

از Node.js در [.nvmrc](.nvmrc)، در محدودهٔ engine تعریف‌شده در
[package](package.json)، و npm 12 استفاده کنید.

```sh
npm ci
npm run validate -- full
```

[فهرست مرجع](.agents/validation.json) هر هشت بررسی الزامی مرحله را تعیین
می‌کند. تست واحد در Node، با پاسخ مصنوعی fetch و بدون بارگذاری dotenv اجرا
می‌شود و `coverage/unit/lcov.info` را تولید می‌کند. تست‌های گردش‌کار در Node
نیز `coverage/governance/lcov.info` می‌سازند. این‌ها اندازه‌گیری واقعی کد
پایه و ابزارها هستند و پوشش وب‌سایت قابل اجرا نیستند. گزارش commit نمی‌شود.

[مشارکت](CONTRIBUTING.fa.md)، [راهنمای مرحله](docs/bootstrap.fa.md)،
[حفاظت شاخه](docs/branch-protection.fa.md) و [تنظیم Sonar](docs/sonarqube.fa.md)
را بخوانید. هر PR حداکثر **۱۰۰ مورد فایل در GitHub** را تغییر دهد. سقف برای
تفاوت PR است و تعداد کل فایل‌های مخزن را محدود نمی‌کند. وجود فایل محلی، شاهد
اجرای CI میزبانی‌شده، بازبینی یا نتیجهٔ Sonar نیست.
