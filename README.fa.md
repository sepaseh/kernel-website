# Kernel Website

[English](README.md) · [فارسی](README.fa.md)

این پروژهٔ مستقل TypeScript در مرحلهٔ **راهنما (`guidance`)** است. مقدار `applicationReady:false` باقی می‌ماند. مجموعهٔ منتشرشده ۶۶ ماژول اجرایی، ۳۴ فایل تست سورس و سه ماژول پشتیبان تست دارد: قراردادهای HTTP و فرم، خواندن زبان با مرجعیت API، ده کاتالوگ تخت ۱۰۷کلیدی، ابزار ارسال درخواست و CSP، کلاینت و عملیات HTTP قابلیت‌ها، اجرای واقعی ICU و انتخاب پیام، دادهٔ SEO، انتقال خصوصی Web Vitals، ترکیب کلاس‌ها و فونت‌های دارای مجوز و بررسی‌شده. پنج ابزار محلی shadcn/Radix، فیلد با برچسب و توضیح مرتبط، بازخورد محلی‌شده، provider نشست و پوسته، ترجیح پوسته، شمارش معکوس محدود، حرکت با محتوای اولیهٔ مرئی و آداپتر هوک Web Vitals نیز منتشر شده‌اند. فرم ورود، مؤلفهٔ مشترک OTP برای ثبت‌نام و بازیابی، فرم پروفایل، نام کاربری، تأیید ایمیل، تغییر رمز و خروج از حساب نیز با محافظ مالکیت درخواست و نتیجهٔ دیررس منتشر می‌شوند.

[راهنمای دستیار](.agents/README.md)، [ناوبری سورس](docs/source-navigation.fa.md)، [معماری](docs/architecture.fa.md)، [طراحی](DESIGN.fa.md)، [تصمیم‌ها](docs/adr/README.fa.md) و [الگوی ارزیابی](docs/comprehension-evaluation.fa.md) به همین محدودهٔ اجرایی بدون تغییر افزوده می‌شوند. فهرست‌ها فقط به مالک و آزمون منتشرشده اشاره دارند. هوک و آداپتر اختیاری میزبان، بارگذاری خودکار، نتیجهٔ سنجش دستیار یا آمادگی اجرا را ثابت نمی‌کند.

[فرم‌ها](docs/forms.fa.md)، [پایهٔ رابط کلاینت](docs/client-ui.fa.md)، [مالکیت نشست](docs/session.fa.md)، [پشتیبانی کلاینت و سند](docs/client-document.fa.md)، [فونت](docs/fonts.fa.md)، [مرز سرور](docs/server-boundary.fa.md) و [ترجمه](docs/localization.fa.md) مالکیت و محدودیت‌ها را شرح می‌دهند. بسته‌های پشتیبان نصب‌شده صریحاً در [package.json](package.json) ثبت و واردسازی هر بسته به مالک، هویت و مرحلهٔ اجرایی یا نوعی دقیق محدود می‌شود. Next.js نوع‌های حذف‌شوندهٔ سند، آداپتر مستقل هوک Web Vitals و مرز link/router مخصوص مالک قابلیت را می‌دهد. صفحه، layout ریشه، آداپتر درخواست و ترجمه، خط ساخت CSS، مسیر مرورگر، استقرار یا نقطهٔ ورود فریم‌ورک منتشر نشده‌اند. [فهرست دقیق ۲۳۳فایلی](.github/bootstrap-policy.json) مرجع محدوده است.

سقف PRهای به‌روزرسانی نسخهٔ Dependabot صفر است تا انتشار با یک PR باز ادامه یابد. تنظیمات به‌روزرسانی امنیتی مخزن مستقل‌اند و این فایل محلی وضعیت آن‌ها را ثابت نمی‌کند. تنظیم تولیدکنندهٔ مؤلفه و یکپارچه‌سازی CSS به مرحلهٔ برنامهٔ قابل اجرا موکول شده‌اند.

## نصب و اعتبارسنجی

از Node.js ثبت‌شده در [.nvmrc](.nvmrc) و npm همراه آن استفاده کنید. Python 3.14.4 و وابستگی‌های پین‌شدهٔ فونت را در محیط موقت فعال‌شده‌ای خارج از checkout نصب کنید. CI آن‌ها را روی اجراکنندهٔ موقت خود نصب می‌کند.

```sh
npm ci
python -m pip install --requirement font-source/requirements.txt
npm run validate -- full
```

[فهرست مرجع](.agents/validation.json) هر یازده بررسی الزامی مرحله را تعیین می‌کند. تست‌ها در Node یا jsdom جداگانه با React/RTL، Radix، next-intl و next-themes واقعی و پاسخ fetch مصنوعی اجرا می‌شوند؛ dotenv غیرفعال است. تست قابلیت از پیام‌های محدود auth/account و کلاینت HTTP و provider نشست واقعی استفاده می‌کند؛ فقط ناوبری router و سند mock می‌شود. تست مالک Motion و هوک فریم‌ورک، mock و محدودیت متن ثابت خود را مستند می‌کند. پوشش واقعی TypeScript در `coverage/unit/lcov.info`، گردش‌کار در `coverage/governance/lcov.info` و ابزار Python در `coverage/fonts/coverage.xml` ساخته می‌شود. این‌ها شاهد برنامهٔ قابل اجرا یا مرورگر نیستند و commit نمی‌شوند.

[مشارکت](CONTRIBUTING.fa.md)، [راهنمای مرحله](docs/bootstrap.fa.md)، [حفاظت شاخه](docs/branch-protection.fa.md) و [Sonar](docs/sonarqube.fa.md) را بخوانید. هر PR حداکثر ۱۰۰ فایل تغییر می‌دهد؛ این سقف تعداد کل فایل‌های مخزن نیست. تنظیم محلی به‌تنهایی موفقیت CI، سونار یا بازبینی دوردست را ثابت نمی‌کند.
