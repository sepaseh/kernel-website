# وب‌سایت کرنل

[English](README.md) · [فارسی](README.fa.md)

این فرانت‌اند مستقل TypeScript از [نشانگر منبع و موجودی دقیق](.github/bootstrap-policy.json) برای محدودهٔ انتشار و [فهرست مرجع](.agents/validation.json) برای فرمان‌های الزامی استفاده می‌کند. مرحلهٔ application مسیرهای Next App Router، چیدمان ریشه، CSS و مبدل‌های درخواست را با `applicationReady:true`، ۹۰ ماژول محصول، ۳۸ فایل آزمون منبع و سه پشتیبان آزمون منتشر می‌کند. آمادگی به مجموعهٔ کامل سورس اشاره دارد؛ پذیرش درخت دقیق همچنان دروازهٔ کامل و شاهد واقعی سرویس‌های بررسی را می‌خواهد.

صاحبان محلی محصول فرم ورود و حساب، مؤلفهٔ پایهٔ بازبینی‌شده، فراهم‌کنندهٔ نشست و پوسته، ده کاتالوگ تخت کامل با ۱۰۷ کلید، HTTP کوکی با no-store و انتقال درخواست، زبان و جهت API، پشتیبانی خالص CSP و SEO، Web Vitals خصوصی اختیاری و فونت محلی دارای مجوز را فراهم می‌کنند. [معماری](docs/architecture.fa.md)، [فرم](docs/forms.fa.md)، [نشست](docs/session.fa.md)، [بومی‌سازی](docs/localization.fa.md)، [پشتیبانی کلاینت و سند](docs/client-document.fa.md) و [فونت](docs/fonts.fa.md) را بخوانید.

API مستقل مالک احراز هویت، تنظیمات، ماندگاری و ذخیره‌سازی است. آن را با HTTP مصرف کنید؛ import سورس مخزن دیگر، workspace و پیوند محلی مجاز نیست. import بسته مجوز صریح صاحب و هویت دارد. [قرارداد fixture](docs/api-fixture.fa.md) نسخهٔ عمومی API، سورس پاک، وابستگی مستقل نصب‌شده، دادهٔ تازهٔ متعلق به آزمون و ورودی سخت‌گیرانهٔ راه‌انداز را تعیین می‌کند. آزمون مصنوعی مالک Node قرارداد مبدل را می‌سنجد؛ دروازهٔ برنامه جداگانه اجرای واقعی همان fixture مستقل و مرورگر را می‌خواهد.

## نصب و اعتبارسنجی

نسخهٔ Node را از [.nvmrc](.nvmrc)، npm همراه آن و Python 3.14.4 را در محیط فعال و دورریختنی بیرون سورس استفاده کنید. API عمومی نسخه‌ثابت را مطابق [راهنمای fixture](docs/api-fixture.fa.md) مستقل نصب و مسیر مطلق آن را با `KERNEL_API_DIRECTORY` انتخاب کنید؛ سرویس موجود یا مخزن همسایهٔ کشف‌شده جایگزین نیست.

برای نمایهٔ کامل مصنوعی، مقادیر `KERNEL_SYNTHETIC_ENV=1`، `NODE_ENV=production`، `NPM_CONFIG_INCLUDE=dev`، `HOSTNAME=127.0.0.1`، دو مبدأ loopback متمایز و آزاد برای وب‌سایت و API با `PORT`، `WEBSITE_URL` و `API_BASE_URL` هماهنگ و نیز `WEBSITE_INDEXING_ENABLED=false` و `PLAYWRIGHT_BROWSERS_PATH=0` را صریح بدهید. CI از پورت ۳۰۱۰ برای وب‌سایت و ۳۱۰۰ برای API استفاده می‌کند. از نحو محیط پوستهٔ میزبان استفاده کنید، نه dotenv. پیش از بررسی مرورگر، Chromium محلی پروژه و مطابق SDK اعلام‌شدهٔ Playwright را نصب کنید. راه‌انداز تحت مالکیت API راز صرفاً آزمایشی و دادهٔ تازه می‌سازد؛ اعتبارنامهٔ خصوصی ورودی نیست.

```sh
npm ci
python -m pip install --requirement font-source/requirements.txt
npm run validate -- full
```

نمایهٔ فعلی پانزده بررسی الزامی دارد؛ تحلیل کد بلااستفاده، ساخت واقعی تولید و بودجهٔ بسته، مسیرهای مرورگر در حالت اجرایی و گزارش‌محور CSP و مقایسهٔ تصویری Windows را هم دربرمی‌گیرد. React/RTL، Radix، next-intl و next-themes واقعی در محیط واحد ایزوله با HTTP مصنوعی نیز اجرا می‌شوند؛ محدودیت مستند mock راهبری و حرکت حفظ می‌شود. همهٔ سورس محصول، اسکریپت راهبری و فایل واقعی فونت اندازه‌گیری می‌شوند. گزارش تولیدشدهٔ پوشش و مرورگر commit نمی‌شود.

[مشارکت](CONTRIBUTING.fa.md)، [آزمون](docs/testing.fa.md) و [اعتبارسنجی](docs/validation.fa.md) پذیرش درخت دقیق را شرح می‌دهند. هر PR از جمله مستندات نمایهٔ کامل مرحله را اجرا می‌کند و حداکثر ۱۰۰ ورودی GitHub تغییر می‌دهد. تنها یک PR وب‌سایت باز باشد و PR مجاز آمادهٔ بازبینی ساخته شود. نتیجهٔ CI، Sonar و بازبینی میزبانی‌شده را برای head فعلی مشاهده کنید؛ فایل به‌تنهایی موفقیت ارائه‌دهنده نیست.

## یکپارچه‌سازی و عملیات

[یکپارچه‌سازی برنامه](docs/application.fa.md) ترکیب چارچوب، CSS و پیکربندی، پانزده بررسی و شاهد واقعی ساخت، مرورگر، CSP و تصویر با API مصنوعی مستقل را تعریف می‌کند. نشانگر باید با منبع و بررسی تحویل‌شده سازگار باشد و پذیرش ناقص را دور نزند.

ابزار منتشرشده صاحب بررسی fixture، بسته، محیط و تصویر، چرخهٔ فرزند، پیکربندی محافظت‌شدهٔ مرورگر و قرارداد فایل خروجی، تنظیم، سلامت و پاک‌سازی است. import بی‌اثر است و ورودی اصلی پیش از عملیات آمادگی را بررسی می‌کند. fixture Node، مسیر تألیف‌شده و تصویر قدیمی تنها محدودهٔ ثبت‌شدهٔ خود را ثابت می‌کنند. [مرحله](docs/bootstrap.fa.md)، [راه‌انداز](docs/runner-foundation.fa.md)، [بنیاد مرورگر](docs/browser-foundation.fa.md)، [تحویل](docs/deployment.fa.md)، [عملیات](docs/release-operations.fa.md) و [حفاظت](docs/branch-protection.fa.md) را ببینید. استقرار و اجرای workflow مجوز مستقل می‌خواهند.

[مستندات](docs/README.fa.md) راهنمای فعال را از QA تاریخ‌دار و نسخهٔ اولیهٔ بایگانی‌شده جدا می‌کند. [راهنمای دستیار](.agents/README.md)، [ناوبری](docs/source-navigation.fa.md)، [طراحی](DESIGN.fa.md)، [تصمیم‌ها](docs/adr/README.fa.md) و [ارزیابی](docs/comprehension-evaluation.fa.md) مالکیت را شرح می‌دهند. hook و آداپتور اختیاری بارگذاری خودکار یا عملکرد مدل را ثابت نمی‌کند. سقف PR به‌روزرسانی نسخهٔ Dependabot طی انتشار تک‌PR صفر می‌ماند؛ تنظیم امنیتی جداست.
