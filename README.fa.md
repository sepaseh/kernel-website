# Kernel Website

[English](README.md) · [فارسی](README.fa.md)

این پروژهٔ مستقل TypeScript در مرحلهٔ **پایهٔ مرورگر (`browser-foundation`)** است. مقدار `applicationReady:false` باقی می‌ماند. مجموعهٔ منتشرشده ۶۶ ماژول اجرایی، ۳۴ فایل تست سورس و سه ماژول پشتیبان تست دارد: قراردادهای HTTP و فرم، خواندن زبان با مرجعیت API، ده کاتالوگ تخت ۱۰۷کلیدی، ابزار ارسال درخواست و CSP، کلاینت و عملیات HTTP قابلیت‌ها، اجرای واقعی ICU و انتخاب پیام، دادهٔ SEO، انتقال خصوصی Web Vitals، ترکیب کلاس‌ها و فونت‌های دارای مجوز و بررسی‌شده. پنج ابزار محلی shadcn/Radix، فیلد با برچسب و توضیح مرتبط، بازخورد محلی‌شده، provider نشست و پوسته، ترجیح پوسته، شمارش معکوس محدود، حرکت با محتوای اولیهٔ مرئی و آداپتر هوک Web Vitals نیز منتشر شده‌اند. فرم ورود، مؤلفهٔ مشترک OTP برای ثبت‌نام و بازیابی، فرم پروفایل، نام کاربری، تأیید ایمیل، تغییر رمز و خروج از حساب نیز با محافظ مالکیت درخواست و نتیجهٔ دیررس منتشر می‌شوند.

[راهنمای دستیار](.agents/README.md)، [ناوبری سورس](docs/source-navigation.fa.md)، [معماری](docs/architecture.fa.md)، [طراحی](DESIGN.fa.md)، [تصمیم‌ها](docs/adr/README.fa.md) و [الگوی ارزیابی](docs/comprehension-evaluation.fa.md) به همین فهرست موجود محصول افزوده می‌شوند. مرحلهٔ فعلی زمان فعال‌سازی محافظ موجود عملیات پس از commit را نیز اصلاح می‌کند؛ [مالکیت نشست](docs/session.fa.md) را بخوانید. فهرست‌ها فقط به مالک و آزمون منتشرشده اشاره دارند. هوک و آداپتر اختیاری میزبان، بارگذاری خودکار، نتیجهٔ سنجش دستیار یا آمادگی اجرا را ثابت نمی‌کند.

[فرم‌ها](docs/forms.fa.md)، [پایهٔ رابط کلاینت](docs/client-ui.fa.md)، [مالکیت نشست](docs/session.fa.md)، [پشتیبانی کلاینت و سند](docs/client-document.fa.md)، [فونت](docs/fonts.fa.md)، [مرز سرور](docs/server-boundary.fa.md) و [ترجمه](docs/localization.fa.md) مالکیت و محدودیت‌ها را شرح می‌دهند. بسته‌های پشتیبان نصب‌شده صریحاً در [package.json](package.json) ثبت و واردسازی هر بسته به مالک، هویت و مرحلهٔ اجرایی یا نوعی دقیق محدود می‌شود. Next.js نوع‌های حذف‌شوندهٔ سند، آداپتر مستقل هوک Web Vitals و مرز link/router مخصوص مالک قابلیت را می‌دهد. صفحه، layout ریشه، آداپتر درخواست و ترجمه، خط ساخت CSS، مسیر مرورگر، استقرار یا نقطهٔ ورود فریم‌ورک منتشر نشده‌اند. [فهرست دقیق ۳۴۵فایلی](.github/bootstrap-policy.json) مرجع محدوده است.

سقف PRهای به‌روزرسانی نسخهٔ Dependabot صفر است تا انتشار با یک PR باز ادامه یابد. تنظیمات به‌روزرسانی امنیتی مخزن مستقل‌اند و این فایل محلی وضعیت آن‌ها را ثابت نمی‌کند. تنظیم تولیدکنندهٔ مؤلفه و یکپارچه‌سازی CSS به مرحلهٔ برنامهٔ قابل اجرا موکول شده‌اند.

## نصب و اعتبارسنجی

از Node.js ثبت‌شده در [.nvmrc](.nvmrc) و npm همراه آن استفاده کنید. Python 3.14.4 و وابستگی‌های پین‌شدهٔ فونت را در محیط موقت فعال‌شده‌ای خارج از checkout نصب کنید. CI آن‌ها را روی اجراکنندهٔ موقت خود نصب می‌کند.

```sh
npm ci
python -m pip install --requirement font-source/requirements.txt
npm run validate -- full
```

[فهرست مرجع](.agents/validation.json) هر یازده بررسی الزامی مرحله را تعیین می‌کند. تست‌ها در Node یا jsdom جداگانه با React/RTL، Radix، next-intl و next-themes واقعی و پاسخ fetch مصنوعی اجرا می‌شوند؛ dotenv غیرفعال است. تست قابلیت از پیام‌های محدود auth/account و کلاینت HTTP و provider نشست واقعی استفاده می‌کند؛ فقط ناوبری router و سند mock می‌شود. تست مالک Motion و هوک فریم‌ورک، mock و محدودیت متن ثابت خود را مستند می‌کند. پوشش واقعی TypeScript در `coverage/unit/lcov.info`، گردش‌کار در `coverage/governance/lcov.info` و ابزار Python در `coverage/fonts/coverage.xml` ساخته می‌شود. این‌ها شاهد برنامهٔ قابل اجرا یا مرورگر نیستند و commit نمی‌شوند.

[مشارکت](CONTRIBUTING.fa.md)، [راهنمای مرحله](docs/bootstrap.fa.md)، [حفاظت شاخه](docs/branch-protection.fa.md) و [Sonar](docs/sonarqube.fa.md) را بخوانید. هر PR حداکثر ۱۰۰ فایل تغییر می‌دهد؛ این سقف تعداد کل فایل‌های مخزن نیست. تنظیم محلی به‌تنهایی موفقیت CI، سونار یا بازبینی دوردست را ثابت نمی‌کند.

ابزارهای یکپارچه‌سازی حفظ‌شده چهار ابزار مستقل کیفیت را فراهم می‌کنند: تعیین صریح مسیر fixture مصنوعی API، اندازه‌گیری بسته و بودجه، محیط کارایی با فهرست مجاز متغیرها و ابزار فراداده و قفل بررسی بصری. سه فایل آزمون مالک در Node با فایل‌های مصنوعی موقت آن‌ها را بررسی می‌کنند. [آزمون](docs/testing.fa.md)، [اعتبارسنجی](docs/validation.fa.md)، [کارایی](docs/website-performance.fa.md)، [محدودیت بصری](docs/visual-regression.fa.md)، [CSP](docs/website-csp.fa.md)، [دسترس‌پذیری](docs/accessibility.fa.md) و [پایداری آزمون](docs/test-reliability.fa.md) را بخوانید. این ابزارها API یا مرورگر را اجرا نمی‌کنند؛ پایهٔ اجراکننده‌های Node با بررسی آمادگی که پایین آمده، این شواهد را بدون فعال‌سازی برنامه گسترش می‌دهد.

آماده‌سازی تحویل هشت ابزار Node برای کپی و بسته‌بندی دارایی متعلق به آزمون، بررسی آمادگی مرحله، بررسی سلامت با مقصد صریح، اعتبارسنجی و تولید تنظیمات عمومی، پاک‌سازی محدود و اعتبارسنجی مقصد اضافه می‌کند. شش فایل آزمون مالک به پوشش گردش‌کار می‌پیوندند و موارد رگرسیون audit موجود، مالکیت واحد اندازه‌گیری‌شدهٔ خود در Vitest را حفظ می‌کنند. [راهنمای تحویل](docs/deployment.fa.md)، [عملیات انتشار](docs/release-operations.fa.md)، [انتشار](docs/releasing.fa.md)، [آزمایشی](docs/staging.fa.md) و قالب‌های غیرفعال بومی و Docker پذیرش آیندهٔ اپراتور را شرح می‌دهند. سورس غیرقابل اجرا باقی می‌ماند: CLIها پیش از عملیات، نشانگر آمادگی false آن را رد می‌کنند. موفقیت fixture مصنوعی، ساخت Next.js، API نصب‌شده، کانتینر، استقرار یا انتشار را ثابت نمی‌کند. [سابقهٔ تغییرات](CHANGELOG.fa.md) تاریخ واردشده را از شواهد فعلی جدا می‌کند.

[پایهٔ اجراکننده‌ها](docs/runner-foundation.fa.md) شش ماژول Node و شش فایل آزمون مالک با پوشش واقعی برای ورودی صریح، چرخهٔ عمر فرزند مستقیم، راه‌اندازی fixture مستقل و API و خروجی محدود تحلیل اضافه می‌کند. عملیات ورودی وب‌سایت، API، سرور و تحلیلگر ابتدا نشانگر عمومی آمادگی را می‌خواند و مجموعهٔ فعلی با applicationReady:false را رد می‌کند. import فایل، dotenv نمی‌خواند، محیط را تغییر نمی‌دهد و سرویسی آغاز نمی‌کند. آزمون‌ها برنامه‌های مصنوعی Node متعلق به خود، شامل خطا و لغو، را اجرا می‌کنند؛ ساخت یا اجرای واقعی Next.js، API مستقل، مرورگر، موتور Docker یا تحلیل آزمایشگاهی اجرا نمی‌شود. دروازهٔ یازده‌بررسی بدون کاهش حد پوشش یا استثنای سورس، ابزار جدید را اندازه می‌گیرد. [پایهٔ مرورگر](docs/browser-foundation.fa.md) اکنون مجموعهٔ آزمون نوشته‌شده با بررسی نوع، پیکربندی Playwright با آمادگی پیش از عملیات و اجرای کنترل‌شدهٔ visual/CSP را اضافه می‌کند. چهار فایل آزمون Node محافظ‌ها و رفتار تزریق‌شده را اندازه می‌گیرند؛ فایل اجرایی مرورگر، API مستقل و اجرای واقعی مرورگر یا مقایسهٔ تصویر همچنان به آینده موکول‌اند.
