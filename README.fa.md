# وب‌سایت کرنل

[English](README.md) · [فارسی](README.fa.md)

این فرانت‌اند مستقل TypeScript از [نشانگر منبع و موجودی دقیق](.github/bootstrap-policy.json) برای محدودهٔ انتشار و [فهرست مرجع](.agents/validation.json) برای فرمان‌های الزامی استفاده می‌کند. نسخهٔ application-guidance مقدار `applicationReady:false`، همان ۶۶ ماژول محصول، ۳۴ فایل آزمون منبع و سه پشتیبان آزمون را حفظ می‌کند. این مرحله راهنمای یکپارچه‌سازی و سوابق تاریخ‌دار را آماده می‌کند و مسیر، چیدمان ریشه یا ساخت CSS نمی‌افزاید.

صاحبان محلی محصول فرم ورود و حساب، مؤلفهٔ پایهٔ بازبینی‌شده، فراهم‌کنندهٔ نشست و پوسته، ده کاتالوگ تخت کامل با ۱۰۷ کلید، HTTP کوکی با no-store و انتقال درخواست، زبان و جهت API، پشتیبانی خالص CSP و SEO، Web Vitals خصوصی اختیاری و فونت محلی دارای مجوز را فراهم می‌کنند. [معماری](docs/architecture.fa.md)، [فرم](docs/forms.fa.md)، [نشست](docs/session.fa.md)، [بومی‌سازی](docs/localization.fa.md)، [پشتیبانی کلاینت و سند](docs/client-document.fa.md) و [فونت](docs/fonts.fa.md) را بخوانید.

API مستقل مالک احراز هویت، تنظیمات، ماندگاری و ذخیره‌سازی است. آن را با HTTP مصرف کنید؛ import منبع مخزن دیگر، workspace و پیوند محلی مجاز نیست. import بسته مجوز صریح صاحب و هویت دارد. [قرارداد fixture](docs/api-fixture.fa.md) نسخهٔ عمومی API، منبع پاک، وابستگی مستقل نصب‌شده، دادهٔ تازهٔ متعلق به آزمون و ورودی سخت‌گیرانهٔ راه‌انداز را تعیین می‌کند. دروازهٔ نشانگر false آداپتور را با آزمون مصنوعی Node اندازه می‌گیرد و API یا مرورگر واقعی اجرا نمی‌کند.

## نصب و اعتبارسنجی

از Node در [.nvmrc](.nvmrc)، npm همراه آن و Python 3.14.4 در محیط دورریختنی فعال بیرون منبع استفاده کنید:

```sh
npm ci
python -m pip install --requirement font-source/requirements.txt
npm run validate -- full
```

نمایهٔ فعلی یازده بررسی الزامی دارد. React/RTL، Radix، next-intl و next-themes واقعی در jsdom جداشده با HTTP مصنوعی اجرا می‌شوند؛ محدودیت مستند mock راهبری و حرکت حفظ می‌شود. همهٔ منبع محصول، اسکریپت راهبری و فایل واقعی فونت اندازه‌گیری می‌شوند. گزارش پوشش تولیدشده commit نمی‌شود.

[مشارکت](CONTRIBUTING.fa.md)، [آزمون](docs/testing.fa.md) و [اعتبارسنجی](docs/validation.fa.md) پذیرش درخت دقیق را شرح می‌دهند. هر PR از جمله مستندات نمایهٔ کامل مرحله را اجرا می‌کند و حداکثر ۱۰۰ ورودی GitHub تغییر می‌دهد. تنها یک PR وب‌سایت باز باشد و PR مجاز آمادهٔ بازبینی ساخته شود. نتیجهٔ CI، Sonar و بازبینی میزبانی‌شده را برای head فعلی مشاهده کنید؛ فایل به‌تنهایی موفقیت ارائه‌دهنده نیست.

## یکپارچه‌سازی و عملیات

[یکپارچه‌سازی برنامه](docs/application.fa.md) ترکیب چارچوب، CSS و پیکربندی، پانزده بررسی و شاهد واقعی ساخت، مرورگر، CSP و تصویر با API مصنوعی مستقل را تعریف می‌کند. نشانگر باید با منبع و بررسی تحویل‌شده سازگار باشد و پذیرش ناقص را دور نزند.

ابزار منتشرشده صاحب بررسی fixture، بسته، محیط و تصویر، چرخهٔ فرزند، پیکربندی محافظت‌شدهٔ مرورگر و قرارداد فایل خروجی، تنظیم، سلامت و پاک‌سازی است. import بی‌اثر است و ورودی اصلی پیش از عملیات آمادگی را بررسی می‌کند. fixture Node، مسیر تألیف‌شده و تصویر قدیمی تنها محدودهٔ ثبت‌شدهٔ خود را ثابت می‌کنند. [مرحله](docs/bootstrap.fa.md)، [راه‌انداز](docs/runner-foundation.fa.md)، [بنیاد مرورگر](docs/browser-foundation.fa.md)، [تحویل](docs/deployment.fa.md)، [عملیات](docs/release-operations.fa.md) و [حفاظت](docs/branch-protection.fa.md) را ببینید. استقرار و اجرای workflow مجوز مستقل می‌خواهند.

[مستندات](docs/README.fa.md) راهنمای فعال را از QA تاریخ‌دار و نسخهٔ اولیهٔ بایگانی‌شده جدا می‌کند. [راهنمای دستیار](.agents/README.md)، [ناوبری](docs/source-navigation.fa.md)، [طراحی](DESIGN.fa.md)، [تصمیم‌ها](docs/adr/README.fa.md) و [ارزیابی](docs/comprehension-evaluation.fa.md) مالکیت را شرح می‌دهند. hook و آداپتور اختیاری بارگذاری خودکار یا عملکرد مدل را ثابت نمی‌کند. سقف PR به‌روزرسانی نسخهٔ Dependabot طی انتشار تک‌PR صفر می‌ماند؛ تنظیم امنیتی جداست.
